# AS2-W 训练守则

适用范围为 AS2-W 滚动、踏步、训练评估、模型导出及实机接入。后续启动训练、续训、修改控制接口或发布权重前必须阅读并执行。每个新作业的运行契约应记录本守则版本、训练代码版本、权重来源及各项检查证据。冒烟或诊断作业必须单独标记为仅仿真，不能作为验收结果。

## 1. 策略和遥控范围

- 滚动和踏步使用独立训练、独立权重、独立控制契约。滚动策略以四轮接地滚动为目标，训练并验收前进、倒车、左转、右转和停稳。纯左移、右移、斜向平移不属于滚动验收。
- 滚动速度课程从零速逐档扩展，直线目标上限为 3 m/s。每档通过对应速度的跟踪、姿态、接触和制动门槛后才解锁下一档。左右转分别覆盖原地和低速弧线。高速弧线需要独立验证后才能开放。
- 遥控采用连续杆量。训练、仿真和部署必须使用一致的死区、零点、限速、加减速约束、滤波、坐标系、控制周期和输入输出语义。满杆上限取当前已验收速度。零指令驻停、失联保护和急停分别验收。

## 2. 训练随机化

- **初始状态**。混合标称 fixed stand、关节角带偏差的站姿和实机接管初态。对髋、腿、膝设每轴偏差，覆盖相关的蹲伸、左右不对称和前后负载差，同时采样机身高度、横滚、俯仰及合理的初速度。优先按实机记录成组采样。仿真代理与实测范围分别标记。采样必须满足软限位、无穿模、合理支撑和可稳定站立。
- **通讯与观测**。分别建模 LowState 数据龄、动作传输时延和电机响应滞后，包含抖动、整帧丢失、重复帧和上一有效帧保持。记录失联超时和恢复行为。编码器和 IMU 每回合偏置与逐帧噪声分开。范围优先由带时间戳的实测数据确定，避免重复计算同一段时延。
- **物理与执行器**。随机化机身质量、质心、相容惯量、轮地静动摩擦及各轮摩擦差异。分别扰动腿和轮的执行器响应、增益和关节阻尼。每项注明单位、采样范围、采样频率和实测或代理来源。随机化仍须满足下述硬限制。
- **随机推动**。仿真中对静站、直行、转向、制动分别施加有界的随机推力或冲量，采样方向、强度、作用位置和时机。记录是否恢复、恢复时间、轮地接触及约束违规。训练推扰与验收推扰使用独立种子。
- 保留无扰动对照。先做单项消融，再做组合扰动。验收工况、种子、初始姿态和扰动序列留出，分别报告典型表现和最差样本。

## 3. 硬约束和姿态

- **角度 90%**。每轴使用校准过的硬限位和验证过的 fixed stand 参考角。以参考角为基准，朝上下限的可用行程各保留 90%。腿关节命令限幅与实测越界监测都要生效。连续旋转的轮轴用已核对的轮速和力矩限制，并独立核对角度回绕。
- **力矩 90%**。每轴控制在当前已验证的可用力矩上限的 90% 内。力矩核对包含位置 PD、速度 PD 和前馈的合计，并考虑速度、温度或电流降额。仿真和实机下发链路都需要可验证的执行器饱和或保护。日志记录峰值、饱和次数和持续时间。仅用奖励惩罚不能替代硬限制。
- **站姿和轮地接触**。约束后腿后倾角和小腿离地净空，避免后腿、膝、小腿或机身触地。以机体系检查同一前后对的左、右腿端顺序及最小间距，避免大交叉和自碰。限值从校准站姿、机器人几何和支撑稳定性确定，训练与验收使用同一口径。滚动阶段记录四轮离地时长和接触载荷，超过约定的短暂卸载门槛即失败。
- 仿真越限、摔倒、非轮触地或触发保护的回合按失败统计。实机侧需要独立的超时、限位、力矩和安全停机保护。

## 4. 动作与权重切换

- 正常动作从 **fixed stand** 起步，经受限过渡进入目标动作，退出时先减速并停稳，再经受限过渡回到 **fixed stand**。
- 权重切换走 **旧策略 → 减速停稳 → fixed stand → 新策略 → fixed stand**。切换以已稳定站立、数据新鲜、目标连续、轮地接触和约束有效为条件。按新模型契约初始化动作历史、相位、滤波和轮角参考。核对切换首帧，以及 100% 接管后首 0.5 秒内的角度误差、关节速度、动作反向和力矩。
- 通讯失效、失稳或硬件保护触发时执行已验证的安全处置。只有在控制和反馈有效且状态允许时才执行正常回站流程。

## 5. 多仿真器验收和发布门槛

- **同一候选权重**必须在 **MuJoCo 和 Isaac Lab/PhysX** 跑完整验收。记录模型哈希、仿真器版本、控制契约、种子和失败回合。核对电机槽位、方向、零位、观测单位、腿位置/轮速映射，以及导出前后的离线推理一致性。
- 两个仿真器都要模拟真实手柄操作。覆盖连续推杆、细推、减速、反打、前后直行、左右原地转、低速弧线、松杆、断流恢复、正常退出及 fixed stand 中转的权重切换。覆盖已开放的各速度档以及留出的初态、摩擦、延迟和推扰。
- 记录速度和转向误差、转向方向、侧滑、接管冲击、角度和力矩峰值、非轮触地、轮离地、自碰、制动时间和距离、停稳后漂移。松杆按制动段和停稳后 10 秒驻停分别计分。高速制动使用经校准的时间和距离预算。
- 启动验收前写明每场景门槛和留出样本数。某个速度、方向、随机域或仿真器未通过时保留失败证据。未完成双仿真器验收的权重只可用于训练或仿真预览。进入实机闭环前还须用真实手柄和 LowState 做只读影子回放，验证约束和切换链路。


## 6. 模型导出与部署交付

- 每个交付候选必须提供训练检查点和可独立加载的 `policy.onnx`。记录模型哈希、对应检查点、ONNX opset、输入输出名称、形状、类型和控制周期。用同一批逐帧观测比较训练模型与 ONNX Runtime 输出，记录误差、复位和历史状态检查。滚动与踏步各自发布，按各自的控制契约核对。
- 沿用已验证的 AS2-W 部署规则。提供版本化 `deploy.yaml` 或等价配置，以及可逐项核对的映射表。写明策略索引、关节名、实机电机槽位、方向、零位和单位，明确观测排列、IMU 坐标约定、轮角回绕、动作历史与复位。写明腿位置与轮速的动作映射、缩放、偏置、限幅、PD 增益、角度和力矩 90% 保护，以及遥控死区、限速、滤波和加减速约束。映射或硬件标定变更需重新验证。
- 随权重交付部署说明和可执行脚本，写明依赖、配置路径、启动命令、验收记录及回退步骤。脚本默认提供离线回放或只读影子模式，并可核对 ONNX 哈希、配置和电机映射。实机闭环入口须明确授权，执行 fixed stand 中转、数据新鲜度检查、切换保护和故障回退。记录测试命令与输出，确保部署可复现。
- AS2-W 当前以锁定版本的宇树官方 URDF、碰撞网格和 SDK 为项目依据。记录版本与哈希，明确区分仿真关节顺序与硬件 DDS 槽位。官方资料中未核实的槽位、正负方向、零位或硬件降额留空，离线和仿真可以继续，实机闭环预检必须拒绝该配置。

## 7. 训练到部署交付清单 v3

本节适用于滚动、踏步、楼梯、起身、站姿保持及多策略组合。交付方应能用同一组输入重现 **模型原始输出 → 动作包装 → 最终控制目标 → 下一帧状态**。按实际技能声明启用模块。无关能力标记 `not_applicable` 并说明原因，未运行的测试标记 `not_run` 并注明补测责任方。研究交付允许只带训练仿真证据。项目正式双仿真验收仍按第 5 节执行，只运行与声明技能有关的工况。项目既定 ONNX 交付与 90% 硬保护仍适用。

### 所有策略必交

- README 首页写明版本、日期、负责人、最终模型哈希、技能、输入输出及频率、入口和终点、各场景通过数与总数、失败与未验证范围、真机状态及建议用途。视频演示和正式验收分别标记。
- 交付包提供 `manifest.yaml` 或等价索引，使用相对路径。外部大文件用固定版本地址并提供大小、SHA256 和获取方式。包内校验清单排除自身，压缩包 SHA256 单独发布。训练服务器路径只作溯源。
- **C1 版本溯源**。选中输出 checkpoint、部署模型和初始化旧权重分别列出哈希。保存 run ID、准确启动命令、训练当时的不可变 commit/tag 或源码快照、实际解析配置和环境依赖。
- **C2 模型接口**。记录输入输出名称、形状、dtype、周期和内置状态。交 ONNX、导出脚本、opset、验证过的 Runtime/架构和同输入原始输出误差。
- **C3 逐维观测合同**。记录索引、单位、坐标系、符号、来源、缩放、裁剪、滤波、时间戳、数据龄和缺测处理，写明历史、相位、上一动作及复位。
- **C4 完整输出链路**。提交动作包装源码、实际参数和全部生效开关。记录关节顺序、尺度、偏置、限幅、补偿、插值、轮角、每个控制状态的 PD/前馈及内部状态。训练、评估和部署的差异逐项标注值、原因与验证状态。包装变化即升版，即使模型哈希相同。
- **C5 入口与退出**。说明允许的姿态和速度、历史初始化、成功和失败条件、退出目标、外层 FSM 依赖和控制权交接。滚动及策略切换按本手册执行 fixed stand。起身按声明的倒地入口和稳定终点验收。
- **C6 仿真与资产**。锁定 URDF/XML、网格、质量惯量、碰撞摩擦、执行器、步长、延迟和随机化的版本及哈希，提供训练仿真复跑入口。
- **C7 逐例证据**。附当前版本的配置、运行命令、初态、种子、通过条件、通过数与分母、首次失败和关键姿态、接触、速度及力矩轨迹。事前固定与技能相符的阈值。
- **C8 最小回放**。提供代表性的固定输入与初始状态，逐帧附模型原始输出、最终控制目标及下一帧历史、相位或轮角参考。附可重算脚本，报告最大误差、最差字段与第一处分歧。先对齐接口，再做同条件闭环。

### 按需模块与交接

- 有速度指令时交 `vx/vy/wz` 语义、采样分布、手柄映射、死区、斜率、超时与逐例跟踪。有制动或驻停时交距离、时间、漂移和失联行为。涉及接管、站立或权重切换时交首帧连续性、阶段时序和回站证据。
- 有轮轴输出时交轮径/减速比、轮速方向、回绕、里程计或锁存、轮载与接触。有历史、相位、积分或包装时交启动填充与复位回放。起身按声明的倒地类型、初速度和稳定保持测试。楼梯按台阶尺寸、地形来源、盲走语义、训练/留出地形及终点测试。步态、高速或多策略按声明域提交接触、净空、峰值、切换和超时证据。
- 训练方给策略关节顺序、物理符号、目标 `q/dq/kp/kd/tau`，写明未使用轴的控制方。部署方以目标 AS2-W 的实测合同核对 DDS 槽位、零位、LowCmd、轮轴模式、控制权及急停。各策略各控制状态分别列增益。
- 在交接记录中列 `R0 收包 → R1 离线对齐 → R2 sim2sim → R3 ARM64/CPRO 只读 → R4 有界实机` 的状态和证据，注明双方负责人和待办。任何尚未达到正式双仿真门槛的专项研发首测，应另列失败项、时限、监测和退出条件，并取得当次现场明确同意。实机权限仅覆盖该次试验。
