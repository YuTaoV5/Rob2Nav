# AS2-W 修复与验收执行清单

| 任务 | 独立训练与验收目录（项目根目录下） | 首轮修复及验证顺序 |
| --- | --- | --- |
| 滚动 | runs/rolling/ | 固定 0.30 m/s 诊断档，先复现首帧触地。分段检查松杆减速、低速保持、fixed stand 交接和 10 秒驻停，再进行完整手柄回放。通过当前档后逐档验证至 3 m/s。 |
| 踏步 | runs/stepping/ | 用 AS2-W 碰撞模型校验单步换重、承重轮和前小腿净空，再验证八方向连续步态、转向和回站。楼梯分别验证接近、首阶、连续阶、退出回站，上下行各记。 |
| 起身 | runs/recovery/ | 预先定义首次稳定站立时限和推扰后恢复时限。后者以最后一次指定推扰为起点，需留足连续站稳 2 秒的观察时间。趴伏、接近站立、左右侧躺分别报告。训练覆盖深侧躺及镜像，验收使用独立姿态和种子。 |
| 权重切换 | runs/integration/switch/ | 仅在集成回放中加载多套权重。每次记录源与目标权重哈希，经减速停稳、fixed stand、新策略接管和最终回站，单独出报告。 |

每个候选单独记录策略哈希、训练配置、控制配置、仿真器、场景、种子、ONNX 校验及逐电机映射版本。原有试次及成绩保留作为对照。两套仿真优先回放相同的初态、手柄命令、延迟和推扰时间序列，逐帧对齐观测、策略输出、关节目标和实际力矩。随机留出验收随后执行。所有用例逐段记录是否通过、首次保护项、触发时刻和部位。试次终止后停止计分。角度与总力矩 90% 硬保护、非轮触地和净空要求按训练守则执行。

## 滚动手柄用例

| 用例 | 当前证据与下一项验证 |
| --- | --- |
| 连续推杆、细推、减速、反打 | Isaac Lab 有专项回放入口。用当前滚动权重和部署一致的死区、滤波、加减速限制，在两套仿真核对整段命令与响应。 |
| 前后直行 | Isaac Lab 0.30 m/s 已有跟踪和制动证据，仍需通过完整手柄序列和驻停。 |
| 左右原地转、低速弧线 | MuJoCo 已覆盖定指令工况，完整试次均未通过。回放连续杆量变化，分开记录运动与松杆结果。 |
| 松杆、零指令驻停、正常退出 | 记录刹停时间和距离、锁定前后漂移、持续驻停及 fixed stand。现有 0.30 m/s 驻停未达 2 cm 门槛。 |
| 断流、恢复与急停 | 分别注入断流和急停，按训练守则核对超时处置、恢复条件和输出。短时丢包结果无法覆盖断流恢复。 |
| 权重切换 | 作为集成试次验证。固定使用当前候选，记录 fixed stand 中转、目标连续性和接管后首 0.5 秒的行为。 |

每个用例在运行前登记门槛与留出样本数。验收以两个仿真器对同一权重的完整结果为准。
