## 路径与环境

仓库可克隆到任意可写父目录，不要求某个服务器账号或硬盘位置。Linux Bash在仓库内执行`source scripts/docs_env.sh`自动定位项目；Isaac入口、CPU Python、外部源码和ROS工作空间由环境变量配置。Windows浏览网站的步骤见环境准备手册。

Web浏览、MuJoCo推理、Isaac训练、机器人本地控制使用不同环境。网站启动不自动恢复训练。SCAN是经典规划器，不训练SCAN权重；PPO导航头和底层MoE是另外的模型。

## 如何理解能力状态

策略、动作原语、训练候选和部署方案分别记录。训练完成、一个成功片段、上游演示、仿真通过都不能代替完整独立验收。研究中的空翻和直立候选仍可能超速、落地失败或振荡；用户实机不稳定的反馈不能由旧仿真成绩排除。

网页实际加载模型以其SHA256、`studio/published_flips.json`和对应评估文件为准。历史报告中的“正在训练”等状态只代表记录当时，不能作为当前进程状态。实机资格需要这台设备的实际验收资料，不能仅修改配置标记放行。

旧英文地址保留兼容入口，网站显示中文正式文档。`python scripts/check_documentation.py`检查网站收录的路径、链接、Bash语法及主要手册的命令选项；该检查不运行GPU训练、导航任务或机器人动作。

第三方源码与资源各自保留原条款，见[第三方说明](THIRD_PARTY_NOTICES.md)。原始模型、配置、日志和哈希证据不因文档整理而重写。
