# 文档校验与迁移记录

更新：2026-10-23。本轮只修正文档与必要的路径/链接支持，不运行新训练，不修改模型验收成绩。

## 1. 覆盖范围

检查网站索引范围：仓库根目录、docs、skills、托爪模块和Studio说明。楼梯、高台、混合地形、前翻、后翻、侧翻、直立、PPO导航统一为“训练手册/仿真手册/部署手册”；SCAN另设仿真与实机手册，明确其不训练导航权重。托爪区分虚拟手演示与真实相机接入方案。

文档保存名优先中文。README、许可文件和第三方约定名称保留。旧英文路径保留兼容入口，网站仅索引中文正文，旧书签和文档内部链接仍能定位。映射见[文档路径映射](https://github.com/YuTaoV5/Rob2Nav/blob/main/docs/文档路径映射.json)。

## 2. 统一的手册结构

每个主要技能手册依次交代目标与边界、环境、输入、操作步骤、输出与验收、排错。训练区分最小流程与正式预算；仿真明确固定归档模型和新训练模型如何选择；部署区分离线检查、SDK接入与设备资格。历史报告保留实验当时的失败与成功，不充当当前安装指南。

先读[新手复现总览](新手复现总览.md)、[术语与验收说明](术语与验收说明.md)和[环境准备与路径约定](环境准备与路径约定.md)。`source scripts/docs_env.sh`从仓库自动确定路径，解释器和外部源码位置可覆盖。未知设备参数使用必须显式赋值的变量，避免尖括号被Shell当成重定向。

## 3. 做了哪些核对

自动检查机器专属路径、站内链接、Bash语法、主要技能手册的模块及选项名称；结果见[校验JSON](evidence/documentation_20261023/static_audit.json)。检查器为`scripts/check_documentation.py`，可在仓库根目录运行：

```bash
python3 scripts/check_documentation.py --output outputs/documentation_audit.json
```

11项文档索引/别名/技能注册测试通过。前端TypeScript与生产构建通过。现有服务器Web和MuJoCo依赖/资产预检、部署profiles及stand→walk_moe离线plan命令通过；环境脚本从带空格目录、任意工作目录source并覆盖解释器也通过。以上操作未初始化DDS、未启动训练或发送电机指令。

网站发布后核对8项技能的三类中文手册、100份正文、201个站内资源及97条旧路径映射，均通过；见[服务器静态检查](evidence/documentation_20261023/server_audit.json)和[HTTP访问检查](evidence/documentation_20261023/http_audit.json)。浏览器另实测旧英文书签和中文文档内跳转，修正了Markdown中文链接被重复编码的问题。静态JSON中本地102份与网站100份的差异来自本地未发布的待开发资料，不表示网站漏掉原有技能。

## 4. 本轮没有证明的事项

语法与选项存在不代表训练能收敛。本轮没有在全新操作系统重装驱动/ROS/Isaac，没有重新跑完各技能GPU训练、所有MuJoCo种子或实机动作。未达标动作、未完成适配及设备资格仍须按手册独立验收。当前服务器具有外部缓存，不等于外部资源已随Git全部分发。

原始artifacts/evidence中的日志、配置和哈希保留，以便追溯；其中的执行机器路径是历史证据，不是可复制的新机器命令。迁移新机器时按中文手册准备源码、依赖和输入，再生成自己的输出。

## 5. 后续维护

新增技能必须带三类手册并写清适用机器人、环境、权重来源、实际参数、输出和失败标准。新增目录或解释器使用环境变量，不提交操作者账号/口令。修改中文文件名时同步映射；发布前重跑检查器与文档测试。更新模型时同时更新实际配置、哈希和验收范围，避免只更新网页描述。
