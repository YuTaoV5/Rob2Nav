# 仓库整理说明

> 文档类型：研究记录。新环境先阅读[环境准备与路径约定](环境准备与路径约定.md)，从当前仓库根目录设置变量。历史报告中的成绩、模型编号和运行状态属于记录当时；当前是否可执行、是否通过，以对应技能中文手册及实际模型/评估文件为准。原始配置和日志仍保留在归档中，不能原样执行其中的机器路径。


本仓库包含 Go2 无地图导航项目及相关研究清单；原工作区中无关的数据融合项目未混入本仓库。

与远端已验证工程相比，发布时作了以下整理：

- 增加主 README、许可说明、视频与评估导航。
- 将 RoboGauge 固定版本随仓库提供，保留上游原始文件、模型、资产和许可；不使用嵌套 Git 仓库。
- `setup.sh` 改用源码快照哈希检查，不依赖 vendor 目录中的 `.git`。
- `run.sh` 支持 `GO2_PYTHON`、当前仓库 `.venv` 和原服务器环境。
- `go2_nav.report` 从快照元数据读取上游版本，并能汇总随仓库附带的历史评估数据。
- 去掉重复传输压缩包、缓存和环境目录；保留视频、模型和原始评估材料。

环境物理、传感器、RoboGauge 接口、反应式导航和 PPO 训练算法在整理时未改动。原服务器专用用法保存在 [USAGE.md](项目使用说明.md)，新克隆应按根目录 README 安装。
