# 新手复现总览

继续当前空翻实验或更换GPU服务器，请直接从[空翻训练交接与新服务器续训指南](空翻训练交接与新服务器续训指南.md)开始；其中的便携配置不依赖旧服务器的输出路径。

先选择你要做的事。只浏览资料、运行物理仿真、训练模型、连接实机，是四种不同任务，使用的环境也不同。本文和同目录手册从你自己克隆的仓库出发，不要求某个账号、硬盘目录或云服务器。

## 1. 先认识文件与命令

不熟悉FIXSTAND、策略、检查点或验收等词时，先看[术语与验收说明](术语与验收说明.md)。

仓库根目录是包含`README.md`、`studio/`、`skills/`的文件夹。下文“在项目根目录运行”就是在终端进入该文件夹；不要进入某个`skills`子目录再运行`python -m ...`。

命令块标记`bash`时，在Linux Bash执行；标记`powershell`时，在Windows PowerShell执行。`$变量`是Bash写法，`$env:变量`是PowerShell写法，不能直接混用。多行Bash末尾的反斜杠表示命令续行，后面不能再加空格。

## 2. 依次完成，不跳过验收

1. 克隆仓库，准备需要的环境，保存依赖版本。
2. 先运行文件/模型检查；缺少外部源码或权重时按手册获取，不用全零观测或其他机器人权重代替。
3. 训练先跑32环境、2更新等最小流程，确认确实保存模型和完成记录，再运行正式预算。
4. 用固定权重、独立种子做仿真，阅读完整`summary.json`，同时检查动作、首尾站姿和物理约束。
5. 保存命令、实际配置、权重SHA256、日志和原速完整录像。训练结束、进程退出0、奖励增加，都不能代替动作验收。

## 4. 如何理解历史结果

操作手册描述“怎样做”；历史报告描述某个固定模型、种子和场景“实际发生过什么”。两者分开阅读。`artifacts/`和`evidence/`中的原始日志、配置与哈希可能记录原执行机器路径，它们是来源证据，不是新机器的操作说明；不要直接执行历史`command.json`。

没有实际模型、输入适配或设备验收的功能，会在手册明确标为方案或未完成。可复现一个失败结果，不代表该技能已经合格。本轮文档校验不会把未通过动作改成通过，也不会宣称重新跑完全部GPU训练或实机动作。
