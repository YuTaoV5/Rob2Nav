# 减少热切换中的重复动作

仿真默认使用紧凑过渡；`--legacy-transitions` 保留中立站姿和固定2秒入口的对照路径。实机服务仅在设备资格记录明确列出旧/新完整合约摘要对 `compact_switch_pairs` 时允许对应短路径，不能沿用仿真结果获得硬件资格。Go2 Edu 键盘与地形交接说明见 [Go2 Edu 热切换](GO2_EDU_HOT_SWITCH.md)。

## 当前行为

- 相同普通技能连续出现时保留当前策略，只更新速度与驻留时间。该能力由共用序列器原本提供，本次没有把它计为新增优化。
- 收到切换请求后先将速度渐归零。稳定支撑持续至少0.3秒、当前实测关节与新入口最大差小于0.6rad时，当前和目标均属于已验证的 `stand` / `walk_moe` / `sideflip69` 组合时直接进入新入口，省略绕回中立站姿的EXIT阶段。腾空中的原子动作仍须结束并落稳。
- 入口使用五次曲线，时长按最大姿态差计算：`clip(1.875 × 差值 / 1.2, 0.35, 2.0)` 秒。实际关节参考仍受原有速度、加速度和力矩约束；时长达到不代表自动放行。
- 入口期间开始新策略观测与历史预热，WARMUP阶段继续核对新epoch、输出有效性和支撑稳定。没有实施两个不同动作策略的无条件混合，也没有跳过动作模仿技能的入口姿态。
- 必须同时满足姿态容差、稳定支撑，以及实际Kp误差<0.05、Kd误差<0.01，才能离开入口；WARMUP提交也检查增益。普通策略输出再渐入，原子技能仍须ARMED和显式trigger。
- 紧凑入口6秒仍未满足条件、但四足站稳时，只尝试一次中立恢复；再次超时进入FAULT。MLP及 `stand_soft`、`stand_stiff` 等未获紧凑路径验证的配置保留完整2秒承重入口和中立恢复路径。

Kp变化率仍为15/s，Kd为2/s，交接力矩变化率150Nm/s。原生策略激活后的动作本身没有被这些交接指标冒充为全程低力矩变化；原子动作和交接阶段分别记录。

## MuJoCo对照

确切输入、源文件哈希、通过与失败原始摘要见 `artifacts/compact_switch_20261021/`。普通序列为stand→MoE→stand，每步驻留1秒；侧翻序列为stand→MoE→sideflip→MoE→stand。相同配置下比较旧路径与紧凑路径。

| 对照 | 旧路径 | 紧凑路径 |
| --- | --- | --- |
| 普通序列seed9411时长 | 24.626s | 18.690s |
| 普通序列seed9412时长 | 24.622s | 18.732s |
| 侧翻组合seed9413时长 | 44.616s | 35.406s |
| 普通序列全关节累计运动量，两个种子均值 | 17.334rad | 16.585rad |
| 侧翻组合全关节累计运动量 | 75.047rad | 77.104rad |

普通序列用时约减少24%，侧翻组合约减少21%。侧翻组合的总关节运动量没有减少，不能把缩短等待解释为全程运动量降低。三种初始朝向0°/±30°的紧凑侧翻组合均完成；额定速度比仍约1.084，未通过实机速度安全要求。

初版给低刚度站姿也缩短入口时出现姿态包络失败，失败摘要保留；因此最终实现保留这些站姿的完整入口流程。五配置扩展测试中，最终紧凑模式和旧路径对照仍都在stand_soft预热阶段发生相同姿态包络失败，均未通过，不能称为低刚度策略已验证。扩展MLP→MoE紧凑切换也出现姿态包络失败，已从最终快捷路径排除，保留完整旧路径。带视频的最终侧翻回归通过，具体结果以归档摘要为准。单一机器人模型、固定场景的少量种子不代表广泛扰动鲁棒性。

复现示例（解释器需具备项目MuJoCo与策略依赖）：

```bash
MUJOCO_GL=egl OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python -m rob2nav.deployment.verify_mujoco \
  --asset source --sequence artifacts/compact_switch_20261021/gait.json --seed 9411 \
  --max-seconds 70 --output outputs/compact_new
# 在新输出目录加 --legacy-transitions 运行旧路径对照。
```

## 导航服务恢复

Studio网页8765、普通导航8768、SCAN8769及SCAN桥是独立进程。只启动网页不能恢复导航画面。本次恢复了全部进程的supervisor管理；仓库 `deployment/start-studio.sh` 在supervisor存活时也检查并启动全部五个服务。容器重启后仍须由宿主启动流程调用该脚本；autorestart只在supervisor本身运行时有效。本地8766另需SSH隧道。

页面连接失败时现在显示物理服务暂不可用和自动重连提示，恢复后清除连接错误，不再一直停留在“等待初始化”。

最终v3匹配回归：标准侧翻组合35.650秒完成；MLP混合序列在紧凑与旧路径均发生姿态包络失败，因此默认网页技能盘仅展示stand、walk_moe、sideflip69，其余通过“展开实验性技能”访问。没有宣称MLP或低刚度组合通过。
