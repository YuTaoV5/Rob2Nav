Studio 的「创建实验」使用 Go2 / AS2-W 切换。AS2-W 侧包含滚动、踏步和起身的正式配方，并提供原有奖励实验与配置入口。

整理历史产物前，先核对训练脚本和 Studio 目录索引对原路径的引用。文件分类索引记录的是整理时的仓库快照，权重状态以各版本的评测和发布说明为准。

提交前按 [项目上传守则](UPLOAD_RULES.md) 核对目录、文件范围和发布状态。
