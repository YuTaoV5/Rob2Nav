# 术语与验收说明

| 术语 | 本项目中的含义 |
|---|---|
| 仓库根目录 | 包含README、skills和studio的文件夹；`python -m`命令从这里执行 |
| 虚拟环境/解释器 | Python及其依赖的一套安装；Web、CPU仿真、Isaac和机载控制各自使用相容环境 |
| 权重/检查点 | 神经网络参数；训练检查点还可能包含优化器，不能只按文件名判断好坏 |
| SHA256 | 文件内容的指纹；用它确认评估、视频与网页实际加载的是同一模型 |
| YAML/JSON | 记录参数的文本文件；实际保存配置比“使用默认参数”的描述更可靠 |
| 烟测 | 少量环境、少量更新，验证导入/数据/保存链路；不是技能收敛或通过验收 |
| episode/回合 | 从明确初始状态开始的一次完整任务；不要只选成功片段 |
| seed/随机种子 | 控制随机起点或噪声的编号；调参用过的种子不能当作未见独立验收 |
| MuJoCo/PhysX | 两个不同动力学引擎；一个引擎通过不保证另一个或实机通过 |
| 50Hz策略、500Hz控制 | 分别每20ms推理一次、每2ms输出一次；不能按500Hz重复更新50Hz历史观测 |
| 物理子步 | 仿真积分步，可能比控制周期更短；只在控制帧采样会漏掉瞬时超速 |
| q/dq/tau | 关节角度、角速度、力矩；通常使用rad、rad/s、N·m，不能混用度和弧度 |
| kp/kd/PD | 用位置误差和速度误差产生力矩的增益；不同技能的数值与变化时序属于控制合约 |
| URDF/MJCF | 机器人结构与动力学模型；模型型号、关节方向、质量与限位不一致时不能直接套权重 |
| FIXSTAND | 本项目约定的标准四足站姿；“动作完成”还需检查前后站姿和保持时间 |
| SDK/DDS/ROS | 机器人接口、通信与机器人软件环境；安装成功不等于控制链和固件已经相容 |
| SSH隧道 | 将远端loopback端口映射到操作者电脑；本机8766与远端8765是两个端口 |

训练结束只表示预算执行完。技能通过还需完整动作、起止状态、接触与关节约束等指标，实机资格另需这台设备的实际验证。原地静止、原地踏步动平衡、直立向前行走是三个目标，不应互相冒充。

所有新命令使用自己的输出目录。保留失败结果，避免删除或覆盖旧证据；遇到未实现功能，按手册写明的边界处理，不用录像、固定根位姿或全零传感器输入冒充复现。
