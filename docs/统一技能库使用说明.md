# 统一部署页面：全技能仿真与连续编排

> 文档类型：研究记录。新环境先阅读[环境准备与路径约定](环境准备与路径约定.md)，从当前仓库根目录设置变量。历史报告中的成绩、模型编号和运行状态属于记录当时；当前是否可执行、是否通过，以对应技能中文手册及实际模型/评估文件为准。原始配置和日志仍保留在归档中，不能原样执行其中的机器路径。


打开网站的“统一部署与热切换”，上方是“空翻、交互与地形技能”，下方保留“编排技能序列”。

## 如何操作

1. 上方点击技能卡，再点击“运行所选技能”。场景重新加载，画面来自实时 MuJoCo。
2. 左键拖动画面旋转，右键或 Shift 拖动平移，滚轮缩放；“重置视角”恢复近景。
3. 地面小格为 **0.25 米**，大格为 **1 米**；棋盘块和红蓝轴固定在世界坐标中，便于比较步幅与位移。画面为 960×640。
4. 运行结束后查看本次评估。没有通过的策略会如实显示失败；启动成功不代表完成技能验收。
5. 切换到其他技能后点击运行，会停止已有的单项或编排仿真，重新初始化场景。

**独立场景与同一物理会话的热切换是不同能力。** 这些新增技能没有全部晋级 `UnifiedRuntime`。上下文、观测维数、控制频率、机器人模型和入口姿态不同，不能将进程切换或重置场景称为无缝热切换。下方已有的站立／行走／侧翻研究序列保持原来的状态机与稳定性门槛。

## 握手交互

选择“伸爪握手”→“打开握手交互仿真”。这会重置独立场景，然后在内嵌页面选择“左爪”或“右爪”。拖动手掌控制点调整水平位置，滑块或滚轮调高度；工作空间显示有效后点击开始。等到接触保持状态，再慢慢移动手掌。切换左右爪前先停止、等收爪完成；也可以重置后选择另一侧。

握手页面保留原有视角控制、撤手和抗扰交互，使用同一网格显示辅助。真实相机和实机步骤仍见 [相机部署](../go2_nav/paw_contact/真实手掌识别与部署方案.md) 与 [实机手册](../go2_nav/paw_contact/虚拟手托爪仿真与部署手册.md)。网页没有实机电机接口。

## 跳跃原语与判定

`python -m studio.jump_demo --root . --output outputs/my_jump_trial` 在真实自由机身模型上只施加关节力矩；机身位姿仅在初始化时设置。不使用机身外力、焊接或根位姿回放。关节顺序显式从 FL/FR/RL/RR 映射至 SDK 的 FR/FL/RR/RL，原语保留前后腿站姿差。

默认参数为蹲伏高度0.25米、蹲伏0.30秒、伸腿高度0.37米、伸腿0.14秒、飞行姿态0.12秒、Kp45/Kd2，参考关节角限速10rad/s。它是有限幅度跳跃演示，不能把目标腿长视为实际跳跃高度。程序单独记录实测机身抬升、无任何地面接触的持续时间、非足端接地和末端站稳情况。跌倒时脚离地不计为腾空。

当前判定要求腾空超过0.04秒、机身抬升超过0.05米、没有非足端接地，最后0.5秒至少90%采样满足三足以上支撑、机身高于0.26米、朝上余弦大于0.97且关节速度小于1rad/s；完整运行还要求最大关节速度比不超过1，关节限位超出不超过0.001rad。该演示不构成硬件验收，也不宣称任意高度跳跃能力。

## 显示实现与复现

背景参照通过 `studio/sim_visuals.py` 添加到 `mjvScene`，不向物理模型添加碰撞体、惯量或传感器目标。只调整显示颜色和离屏缓冲尺寸，不改变地形摩擦、质量、关节参数、控制或感知输入。采用 [MuJoCo 官方可视化接口](https://mujoco.readthedocs.io/en/stable/APIreference/APIfunctions.html#mjv-initgeom)。

```bash
cd studio/frontend
npm run build
node --test tests/composer.test.mjs
```
