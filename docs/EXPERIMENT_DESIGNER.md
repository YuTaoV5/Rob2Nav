# 实验设计与高度目标

实验设计页分为基础配置、运动目标、算法与阶段、奖励函数、感知与课程。

## 方法不是优化器名称

MoE 原生执行器目前仍使用 PPO。冻结适配、渐进解冻、空间注意力、教师/学生输入属于结构或训练流程的选择。PIE、WMP、HIM、WTW、NJU、AME、SEA 方法卡分别展示估计辅助任务、世界模型、条件步态、分层模仿/强化学习和安全屏障等机制。专用训练器未接入的方案明确标为待适配，预检阻止执行；不能将这些方法任意发送给 MoE PPO。

原生解冻预设：仅新增分支（fusion=本次预算）、渐进微调（10%价值预热、60%融合、30%actor）、联合训练（阶段均0，遗忘风险较高）。恢复训练按全局轮次计算，不保证本次预算内经过所有阶段。

## 固定高度训练目标

可选 `body_height_target_m`：0.18–0.50米；可选 `swing_clearance_target_m`：0.04–0.25米。未启用时不增加奖励、不改变旧配置覆盖文件的规范化哈希。

* 机身高度：基座原点高度减去其最近XY地面射线命中高度。仅有限、离地0–0.8米范围评分，平方误差默认权重−1。
* 摆腿间隙：每脚高度减去足下3×3射线最高有限命中高度。仅接触力范数<5N、水平脚速>0.1m/s、间隙0.02–0.5米时评分；四脚掩码平方误差均值，默认权重−0.5。

奖励使用训练真值，不增加 actor 的特权观测。两者是软目标，不是运行指令、峰值抬腿轨迹或碰撞保证；坑上腾跃可能不计分。基座原点不是外壳底面。目标不会修改PD、初始姿态或关节动作尺度。

修改目标后创建新训练或选择仅权重初始化微调；恢复要求原覆盖文件哈希匹配。仿真回放禁止传入这些训练字段，已有权重不会因此即时改变姿态。需要运行时可调高度时，应另外训练条件化策略并同步观测/部署合约。

## 奖励目录与校验

`rob2nav/experiment_schema.py` 是共享目录，包含当前原生基础奖励、导航/课程/风险奖励以及可选高度项。页面显示分类、量纲、公式、说明、风险、适用条件和当前模式有效默认权重。只勾选的覆盖项写入配置；取消恢复模板。

`POST /api/experiment-preview` 返回解析后的奖励与覆盖文件；`POST /api/preflight` 验证执行环境并返回同一奖励解释。运行保存的 `env.yaml` 为最终依据。奖励权重不等于贡献，管理器还按步长处理，各项量纲不同。未启用目标时不能覆盖对应高度奖励；导航移除的速度跟踪等项不能启用覆盖。

## 验证与限制（2026-10-20）

38项Studio测试通过，包含模式默认、目标范围、不可用奖励及旧哈希兼容；前端TypeScript和生产构建通过。服务器 Isaac 原生8环境、2迭代短测，以0.32米机身和0.12米摆腿目标完成，`env.yaml` 确认两个奖励参数和默认权重，训练损失有限。记录位于 `artifacts/experiment_designer/native_smoke`。

首次短测输出目录预建导致启动拒绝，改用未创建的子目录后完成；没有把失败启动算为通过。短测仅验证执行链路，不证明高度跟踪或地形能力提升；原AME窄桩问题仍未解决。新实验源码快照额外包含共享奖励目录。
