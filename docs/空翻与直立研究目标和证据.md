> 文档类型：研究记录。新环境先阅读[环境准备与路径约定](环境准备与路径约定.md)，从当前仓库根目录设置变量。历史报告中的成绩、模型编号和运行状态属于记录当时；当前是否可执行、是否通过，以对应技能中文手册及实际模型/评估文件为准。原始配置和日志仍保留在归档中，不能原样执行其中的机器路径。


本节目标优先于旧的“直立行走”任务：持续迭代前、后、左、右空翻及原地双后足直立；四足标准站姿起始与结束，不要求直立行走。当前目标未完成，不能将已有后翻单技能通过缩小成全部完成。

## 原地直立独立训练

运行目录`outputs/fixstand_upright_stand_static_v1_20261022`，从已归档v3/model_2998恢复，新的优化器，学习率3e-5、std0.08、4096环境、1800更新。32环境2更新烟测已结束，实际YAML确认三个速度指令均为0、有stationary_balance奖励、无交替迈步/腾空奖励，之后才启动正式任务。新控制保持原52维观测和阶段合约，目标不再要求位移或迈步。

奖励强调双后足共同承重、前足离地、姿态高度、低机身速度/角速度、关节速度余量、低动作变化和非足端接地约束；训练仍采用50%标准起点、50%动作段初始化，独立验收必须全部从标准四足起点执行。

新增`upright_stand`验收明确与`upright_walk`分开，旧行走验收不降低：2–5秒保持区间覆盖至少140个50Hz样本，稳定比例≥95%，连续稳定≥2秒，水平漂移≤0.10米、水平速度≤0.08m/s、角速度≤0.5rad/s、关节速度≤2rad/s、相邻目标步长≤0.06rad。还要求直立姿态、双后足实际受力、前足不承重、无身体触地、URDF限位/速度以及首尾FIXSTAND全部通过。独立种子13100–13103由脚本结束后自动运行。

```bash
cp -a artifacts/fixstand_upright_v3_20261022/outputs/fixstand_upright_tight_endpoint_v3_20261022 outputs/
bash scripts/train_upright_stand_v1.sh
```

旧行走v5因新目标不需要行走已停止，保留最后model_4300及停止原因/哈希。SIGTERM未停止子训练进程，核对完整命令和进程组后仅终止了该旧子进程；没有将中途停止记为训练完成或验收通过。

## 右侧翻派生必须正确处理方向

`scripts/export_mirrored_sideflip.py`对参考和69维策略同时做矢状面反射：交换左右腿，髋关节角取反，位置/线速度按极向量处理，角速度与四元数按轴向反射处理；观测中相对旋转的两列和动作历史同时转换。它不是视频翻转，也不是新训练成功。反射两次应还原原数据，导出保留原策略和参考的哈希及未验收标记。

两次MuJoCo探测13200/13201得到正向约+6.249rad，后者明确通过`expected_direction=right`方向检查，但仍出现约1.09倍关节速度、约0.078rad硬限位超出和机身触地，首尾站姿不通过。左右技能不能只按旋转绝对值互相冒充。

PYTHONPATH=. python scripts/export_mirrored_sideflip.py \

python -m rob2nav.mujoco_skill --kind sideflip --policy outputs/right_candidate_new/policy.pt \
