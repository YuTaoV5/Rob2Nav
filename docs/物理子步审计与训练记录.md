## 侧翻：控制帧漏掉了瞬时超速

对v10/model_10695在原PhysX环境执行只读子步审计，500Hz记录4000个物理样本。50Hz控制帧最大关节速度比为0.9427805；物理子步在2.822秒捕获FL_calf_joint速度−27.4534rad/s，相对URDF的15.7rad/s上限为1.7486226倍。子步没有发现硬限位超出或身体触地，首尾站姿通过，但速度约束失败。此前控制帧诊断不能证明逐物理步合格。

另外两次MuJoCo初始化对照中，标准站姿初始化和参考状态初始化均通过准备段，却仍出现落地触地、约1.09倍超速及约0.076rad限位超出。因此仅修改初始化不能解决落地问题。两引擎仍有差异，不能把全部问题归因于采样。

新增`skills/substep_statistics.py`在每次物理更新后累计关节速度、限位超出、机身角速度及非足端接触峰值，控制周期开始才清零。准备段与落地约束奖励读取这些峰值，不写入或重置物理状态。32环境、2更新烟测确认每个控制周期10个物理样本、接触传感器更新周期0.002秒；测试覆盖控制帧之间出现峰值后回零的情况。

侧翻v11目录为`outputs/fixstand_sideflip_substep_peaks_v11_20261022`，从v10/model_10695续训，4096环境、1800更新、新优化器、学习率1e-5、std0.03，保留v4连续衔接和消抖/落地目标。仅该新任务开启子步目标；已经运行的原地直立训练不会追溯获得此改动。

```bash
bash scripts/train_sideflip_substep_v11.sh
```

结束自动导出并使用13400–13403进行左翻独立验收，再生成真实策略/参考反射候选，以13410–13413验收右翻。两侧必须分别检查方向、完整旋转、首尾站姿、身体触地、URDF速度/限位、准备段安静和未剪辑原速视频。反射导出本身不代表右翻通过。

## 后翻：承重入口反事实

统一流程在−15度朝向触发后翻时保存实际关节位置/速度、根位置/四元数、世界线速度和机身角速度，并以相同观测运动学状态启动原生播放。捕获流程seed12509初始站姿失败、速度比1.00255；原生重放seed13500仍初始站姿失败（稳定比例0.8857、误差约0.12858rad），但完整翻转、末站姿及关节约束通过，速度比0.82552。

这表明入口状态分布是实际问题，不能只归因于统一控制器。重放没有恢复求解器热启动或隐藏执行器历史，因此不是完整物理状态克隆；速度差异仍需进一步诊断。上述两次均是诊断，不纳入独立四种子通过率，不改变生产热切换配置。
