## 5. 下一位 agent 的优先操作顺序

1. 先读本套文档和 `manifest.json`，校验模型、源码及证据。连接恢复后核对进程，不根据旧 PID 启动/杀任务。
2. 不重训已完成 v1，不恢复旧空翻或追球队列。独立目录保留原模型和原始失败报告。
3. 完善接触诊断：输出每个接触的 geom/body、世界坐标接触点、法向/力或冲量、足底相对位置、步态阶段；加入真实足底接触阳性计数及可控非足接地阳性验证。保持物理参数和状态不变。
4. 对 seed32121 固定模型/初态/命令重放，保存前后动作、关节目标、历史观测和物理状态，定位后退切换时的策略突变。不要只用命令平滑隐藏原阶跃失败；阶跃和生产命令整形分别测试。
5. 确认机制后设计小规模对照：例如映射后的目标速率损失和接触惩罚，但世界模型想象奖励与真实奖励必须同步；先检查梯度和观测泄露，再短训练。每次只改有依据的因素，记录实际配置、源码哈希和控制初始化合约。
6. 为新训练显式接入 reset-hold，验证 registry 的训练配置确有事件；保留旧历史 wrapper。新的训练必须重新做 smoke 和完整 audit，不能沿用 v1 的 reward=0 误差报告。
7. 完成四个新独立种子：跟踪、转向、停稳、跌倒、逐物理步关节约束、原始目标连续性和非足接地全部通过；完整原速录像复看；适配统一执行后再次验证。此前 `capability_qualified=false`。
8. 平地通过后再实现盲楼梯：先低台阶课程，再上下楼梯、不同朝向/速度/摩擦；训练可向世界模型/critic 给地形特权，但 actor 仍不能接高度图/雷达/线速度真值。真实与想象地形/接触处理需一致，不能使用硬编码平地 relief 代表楼梯动力学。
9. 实现网页参数 schema、预检、独立 Jobs 记录和状态查询，再将新训练纳入工作台。当前独立进程不应伪装成已有 PPO 任务。
10. 完成部署导出、关节映射、增益/延迟/历史初始化和运行时数值对照，再考虑 Go2 EDU 实机验证。仿真通过不自动等于实机通过。

## 6. 交接时应保存什么

每次实验至少保存：固定上游版本、overlay diff 与哈希、依赖锁定、完整实际参数、模型及优化器、日志、运行和退出状态、独立种子原始 JSON、逐物理步失败片段、视频与元数据。大缓存、可重建编译产物和整个环境目录不上传；必要模型、实际配置、复现源码和失败证据应上传。

网站已有性能修复应保留：jobs/inventory 不重复读 TensorBoard，catalog 冷扫描加锁，前端壳先显示。服务器 Rob2Nav 工作树有其他改动，禁止 pull/reset 或整文件覆盖别人的扩展。本次发布通过独立 Git 分支整理，避免污染正在运行的工作树。
