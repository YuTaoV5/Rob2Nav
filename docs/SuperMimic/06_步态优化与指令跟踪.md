# 步态优化与速度、转向指令跟踪

2026-10-26。用户明确“跟踪”指速度、转向指令跟踪。当前不恢复追球、跟人或旧空翻训练。

## 1. 为什么需要这一轮

v1 虽然速度误差较低，但没有证明步态自然。新增只读基线评估（seed33000，8 环境，八阶段各5秒，8000物理子步）发现：机身平均高度约0.19–0.24m，前进阶段约0.216m，站立约0.200m；足底接触高度占比很高，很多腿没有持续至少40ms的有效摆动段。站立与转向时姿态倾角本来较小，因此本轮主要针对低趴、拖脚和目标突变，不能只继续提高 upright 分数。

原始数据与失败结果保持不变。早期按碰撞触点开关计算出的前足DF约0.99，可能只是短暂碰撞分离；它不是“优良高占空比步态”的证据。新定义过滤这种情况，没有完整周期时返回 null，而不是用0或1补齐。

## 2. 指标定义

| 指标 | 计算方式 | 防止误读 |
| --- | --- | --- |
| duty factor（DF） | 完整 touchdown→下一 touchdown 内的接触时长/周期时长，按每腿分别统计 | 周期0.15–2s，连续摆动和总支撑均至少40ms；排除reset及阶段边界；无有效周期为null |
| 原始接触占空率 | 任意有效窗口内接触样本数/样本数 | 单独报告，不能当完整步态周期DF |
| 周期与左右差异 | 每腿完整周期数、平均周期、四腿DF跨度 | 只有四腿都有有效周期时计算完整跨度 |
| stance slip | 足端世界坐标有限差分，在相邻两个物理步足底持续接触时统计水平速度RMS | 排除reset造成的跳变；不是机身坐标足速 |
| 姿态 | roll、pitch、总倾角RMS及横滚俯仰角速度 | 转向速度和不必要摇晃分别统计 |
| 身高与离地 | 机身高度均值/标准差、每足离地高度P95 | 离地扣除0.022m足球半径；本阶段仅平地 |
| 能耗代理 | 实际施加关节力矩×关节速度的绝对功率、按名义质量与实际速度归一化 | 不是电功耗；站立不计算无意义的按距离代价 |
| 跟踪与约束 | 原八阶段速度/转向/停稳误差、跌倒、200Hz关节位置/速度/力矩、50Hz原始目标变化率、非足接地 | 不因步态变好就删除原有失败项 |

物理接触来自Warp活跃碰撞缓冲的命名足底与地面 `dist<=0`，目前是几何接触DF，不冒称有力传感器确认的承重DF。小腿接地单独统计并保留严格失败条件；不能通过把全部小腿划为足底来通过。

参考依据：[Duty Factor Predicts Robust Constrained Quadrupedal Locomotion Across Gait Types](https://arxiv.org/abs/2609.22073)研究了DF与约束地形鲁棒性的关系；[Go2步态对称性工作](https://arxiv.org/abs/2403.10723)强调速度、周期及对称性，而不只比较步态名称。[Walk These Ways 原始奖励代码](https://github.com/Improbable-AI/walk-these-ways/blob/master/go1_gym/envs/rewards/corl_rewards.py)提供支撑期滑移、姿态、动作变化等实现参考。本项目没有照搬其Go1控制器，也没有证明论文在本任务上的结论已复现。

## 3. 第一轮优化假设与实现

新任务 `Go2-Velocity-Gait-V2` 保留350维actor、5帧历史、本体观测与vx/vy/wz；后25个命令槽仍为零。世界模型8步拟合、32步想象不变。

`rob2nav_gait_v2.py` 新增共享的真实/想象**转移**奖励：

| 项 | 初始参数 | 解释 |
| --- | --- | --- |
| 身高 | 目标0.29m，权重−0.4 | 对相对0.05m尺度的高度偏差平方惩罚，改善低趴 |
| 支撑期滑移 | 权重−0.15 | 用相邻两状态及位姿计算世界足速，接触用连续高度软代理 |
| 映射目标变化率 | 权重−1，margin0.6 | 动作差×逐关节scale/dt/限速后，惩罚超余量部分 |
| 膝低位 | 权重−0.1 | 膝点低于0.08m的连续代理，不能代替碰撞检查 |
| 支撑不足 | 权重−0.1 | 运动至少1.5软支撑、站立至少3.5；避免通过全足悬空逃避滑移惩罚 |
| 直行横向对称 | 权重−0.03 | 只约束直行/站立时左右足横向中点，不强迫同相关节姿态 |
| 关节速度余量 | 权重−0.1，margin0.8 | 保留逐物理步独立限速验收 |

保留原速度、转向、站停与直立奖励。训练中软接触只是可微代理，真实验收使用独立物理碰撞；不能用代理分数宣布接地通过。DF首先作为有完整周期的评估和选模指标，没有直接逐帧强制所有速度DF=0.5，避免悬足/拖脚刷分。

真实训练只在env.step前读取状态供奖励计算，不向actor加入特权信息，不改qpos/qvel或求解器；本轮训练在创建环境前实际安装reset-hold。新奖励改变后重置critic，actor和world model从v1完整检查点续训。

## 5. 如何决定下一轮

先确认新的高度、有效摆腿周期和支撑滑移确有改善，再检查同seed速度/转向误差是否退化；站停阶段不要求出现摆腿周期。如果仍无有效周期，不把raw DF接近1当作成功，应诊断接触/离地与模型预测误差，必要时再设计步态相位条件或完整周期课程，先做小规模对照。

严格四种子的物理门槛、跟踪和停稳都须通过，且原速完整复看后才考虑统一部署。`independent_physical_gate_passes`仅统计物理子集；`capability_qualified`依然false，不能因其中某一列好看就晋级。下一轮只按具体失败证据变更参数，禁止相同条件无限长训。

## 6. V2实际结果与下一轮单因素对照

V2已完成2000轮。独立33120–33123四组均无跌倒、无非足接地，实际关节速度和位置/力矩未越限；但原始目标变化率为1.297、1.357、1.327、1.293，均未通过。峰值仍集中在后退切换后约0.12秒的左前小腿，不能因为身体姿态更好就忽略。

同seed33000的前进配对：高度约0.216→0.291m，支撑期滑移约0.061→0.048m/s；原先没有通过40ms连续摆动条件的前进周期，新版四腿分别有52/46/47/45个完整周期（8环境汇总）。这是实测改善，但速度跟踪误差存在小幅变化，需要与姿态收益一起权衡，不称全部优化完成。

下一轮V3只将目标速率平方超额的12关节 `mean` 改为 `max`，其余奖励设置不变。单关节异常在mean中被稀释12倍，新增机制测试验证了这一点。V3从V2/model2000继续800轮，先32×24烟测，再正式训练，独立33220–33223评估。它沿用相同观测/物理任务ID，实验版本由run_name、实际settings、源码哈希区分；不是另一个传感器架构。
