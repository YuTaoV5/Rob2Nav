# SuperMimic 复现入口

更新：2026-10-26。本文档对应仓库内 `skills/supermimic` 的代码、最终检查点、实际配置和原始评估报告。

**现在可以复现 Go2 平地速度指令行走训练、冻结模型评估和视频演示；盲楼梯尚未实现和验收，当前模型也未完整达标。** 不要把论文演示、训练结束、视频中的正常行走等同于本项目全部能力通过。

按顺序阅读：

1. [原理与代码说明](01_原理与代码说明.md)：论文、第三方 Go2 实现、本项目改造的区别。
2. [服务器部署与环境安装](02_服务器部署与环境安装.md)：新服务器从零安装，固定源码和依赖。
3. [训练与恢复操作手册](03_训练与恢复操作手册.md)：烟测、正式训练、恢复、参数解释。
4. [仿真评估与网站部署](04_仿真评估与网站部署.md)：加载已训练权重、逐物理步检查、录像、网页发布。
5. [已完成结果与后续交接](05_已完成结果与后续交接.md)：真实结果、失败项、下一位 agent 的操作顺序。

所有命令均在 Linux Bash 中执行。`$ROB2NAV` 是本仓库路径，`$SUPERMIMIC_HOME` 是独立的 Go2 上游源码目录，`$VENV` 是独立 Python 环境。先完成安装章节的变量设置，再执行后续章节。不要复制历史报告中的服务器绝对路径作为新服务器配置。

快速查看现有成果（安装完成后，无需重训）：

```bash
cd "$SUPERMIMIC_HOME"
export CHECKPOINT="$ROB2NAV/skills/supermimic/checkpoints/velocity_blind_flat_v1_model_12000.pt"
"$VENV/bin/python" scripts/eval_velocity.py \
  --checkpoint "$CHECKPOINT" --seed 32200 --num-envs 2 --stage-seconds 2 \
  --initialize-hold-targets --audit-body-contact \
  --output reproduction/velocity/local_smoke.json
```

预期：程序完成八阶段评估并写 JSON。**预期不包含能力合格**：已归档的相同烟测检测到小腿接地。
