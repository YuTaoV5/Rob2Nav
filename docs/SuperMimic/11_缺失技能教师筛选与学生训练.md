# 缺失技能：GitHub教师 → SuperMimic学生

## 当前规则

用户2026-10-26明确要求：教师能稳定做出目标动作即可，其他优化交给SuperMimic。因此教师资格按动作功能判断，关节速度、限位、目标连续性等仍记录，不能删除失败数据；这些不再提前阻止功能教师用于仿真教学。学生训练加入约束奖励，功能成功率与物理包络分别报告；这不自动构成Go2 EDU实机资格。不能把外部权重改名为自训学生。

## SuperMimic学生与教师的区别

新增独立任务Go2-SuperMimic-Recovery-V1：学生和世界模型从零训练；actor仍350维5历史本体与全零任务命令，不含高度图、球坐标或基座线速度真值。世界模型拟合8步、想象32步不变。新增共享真实/想象恢复奖励：朝上程度、身高、站姿，辅以关节速度、目标变化率及翻滚角速度惩罚。恢复任务取消“倾倒即结束”，只保留超时；随机倒地是正常reset初态，不在动作过程中写物理状态。

该技能采用明确的新控制合约PD30/.8、延迟0、复位目标保持当前关节角，不能与旧平地控制合约混淆。教师驱动50%环境，2500–3500轮渐退，最后500轮纯学生；教师执行动作与回放一致。辅助actor-SGD权重.05、lr1e-4，教师失败/越限过渡不从世界模型数据中删掉。辅助BC是明确扩展，并非声称上游论文原生如此。

32环境24轮烟测已完成：教师544帧、BC更新16次、actor梯度非零，真实/想象奖励误差0。学生独立评估烟测2环境3秒、600物理步已执行，恢复0/2，只说明评估链通，不是学生合格。

## 代码与命令

新增文件在skills/supermimic/overlay：rob2nav_recovery.py负责任务、共享奖励和FR教师；scripts/train_recovery_supermimic.py负责学生训练及教师数据；scripts/eval_recovery_supermimic.py负责学生独立功能与物理报告。recovery_pipeline.py是带防重状态的正式训练衔接。先按照00–03手册安装固定上游环境与overlay，再下载教师源码（不要覆盖已有目录）：

```bash
export FR_HOME="$HOME/FR-Net"
git clone https://github.com/lu-yidan/FR-Net.git "$FR_HOME"
git -C "$FR_HOME" checkout 85c872d9bef0a74716d8d3fb1e89606c8a42101e
export TEACHER="$FR_HOME/logs/GO2_recovery/pretrained_recovery_v3/model_2000.pt"
cd "$SUPERMIMIC_HOME"
"$VENV/bin/python" scripts/train_recovery_supermimic.py \
 --task Go2-SuperMimic-Recovery-V1 --num-envs 32 --iterations 24 \
 --buffer-len 40 --imag-batch 128 --warmup-iterations 8 \
 --critic-warmup-iterations 4 --actor-ramp-iterations 4 \
 --driver-policy "$TEACHER" --driver-frac .5 --driver-fade 800 1200 \
 --seed 35101 --run-name recovery_fr_teacher_smoke_v1
```

确认recovery_audit.json训练完成、reward_max_error=0、teacher_frames和bc_steps非零后，再以新run_name设置4096环境4000轮、buffer400、imag4096、warmup400、criticwarmup200、actorramp400、lr.0001、actor-lr-scale.25、lr-decay4000、lr-final-frac.3、driver-fade2500 3500、seed35111。从零训练，不传resume。

```bash
"$VENV/bin/python" scripts/eval_recovery_supermimic.py \
 --checkpoint "$STUDENT_CHECKPOINT" --seed 35120 --num-envs 128 \
 --seconds 12 --output recovery_seed35120.json
```

完整固定参数从实际recovery_contract.json读取。已有服务器任务不可重复提交。其余技能遵循同一链路：公开来源/提交/许可/SHA → 关节和观测动作合约 → 功能演示 → 世界模型与学生烟测 → 有界正式训练 → 学生独立验收 → 原速视频，只有最后一项才作为首页自训演示。
