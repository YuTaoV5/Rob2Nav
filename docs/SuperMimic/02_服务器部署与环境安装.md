# 服务器部署与环境安装

## 1. 先准备什么

实测环境为 Linux、Python 3.12、NVIDIA L40（约 46GB）、驱动 580.126.09、CUDA 可用的 PyTorch 2.14.1+cu130、mjlab 1.6.0、MuJoCo/mujoco-warp 3.11.0、warp-lang 1.18.0。驱动和显卡不由 pip 安装；其他显卡、驱动或依赖版本需要重新烟测，不能承诺同样速度或数值。

无需机器人实机即可训练和看视频。不要将 GPU 训练环境与网站 Python 环境混装。

在自己电脑连接服务器；以下地址全部换成自己的：

```bash
ssh -p SSH端口 用户名@服务器地址
```

登录后检查：

```bash
nvidia-smi
python3.12 --version
df -h .
git --version
```

需要 Python 3.12 的 venv、Git、ffmpeg 和 EGL。Ubuntu 可安装系统工具（需要管理员权限）：

```bash
sudo apt-get update
sudo apt-get install -y git python3.12-venv ffmpeg libegl1 libgl1
```

若发行版软件源没有 Python 3.12，请先通过该发行版支持的方法或 Conda 安装；不要直接把命令中的版本换成任意 Python 后视作同环境。

## 2. 定义自己的目录

下面统一使用用户目录。数据盘用户可以只修改 `WORK`。

```bash
export WORK="$HOME/robot-work"
export ROB2NAV="$WORK/Rob2Nav"
export SUPERMIMIC_HOME="$WORK/go2-supermimic"
export VENV="$WORK/envs/go2-supermimic"
mkdir -p "$WORK/envs"
```

每次重新 SSH 登录后需重新执行这些 export，或写入自己的 shell 配置。后续所有命令都依赖这四个变量。

## 3. 下载本仓库与固定上游

```bash
git clone --branch codex/supermimic-reproduction \
  https://github.com/YuTaoV5/Rob2Nav.git "$ROB2NAV"
cd "$ROB2NAV"
python3.12 skills/supermimic/verify_resources.py
python3.12 skills/supermimic/install_overlay.py --source "$SUPERMIMIC_HOME"
git -C "$SUPERMIMIC_HOME" rev-parse HEAD
```

本次资源发布在 `codex/supermimic-reproduction` 分支，尚未合并时不要省略 clone 的 `--branch`。

最后一行必须为 `054a13c13285a1c94b2e69dc8ac7331f9a8c71cf`。安装器会检查源码版本、应用 mjwarp 可选告警标志兼容补丁、复制 overlay；遇到不同版本或本地 overlay 修改会停止，避免破坏工作。

上游兼容补丁只处理 `OverflowType` 导入与不存在的告警枚举，不调整物理求解器、接触或奖励。不要通过关闭速度/接触验收来规避安装问题。

## 4. 建立独立依赖环境

```bash
python3.12 -m venv "$VENV"
"$VENV/bin/python" -m pip install --upgrade pip
"$VENV/bin/python" -m pip install \
  --extra-index-url https://download.pytorch.org/whl/cu130 \
  -r "$ROB2NAV/skills/supermimic/requirements.lock.txt"
"$VENV/bin/python" -m pip install --no-deps -e "$SUPERMIMIC_HOME"
"$VENV/bin/python" -m pip check
export MUJOCO_GL=egl
```

锁文件来自实际服务器环境，包含完整间接依赖，适用于相同 Linux/Python/CUDA 系列。镜像源若没有锁定版本，应先恢复官方索引或匹配的软件源，保留安装日志；不要悄悄升级依赖后仍称完全相同复现。

检查运行时：

```bash
"$VENV/bin/python" -c 'import torch,mujoco,mjlab,warp; print("torch",torch.__version__,"mujoco",mujoco.__version__); assert torch.cuda.is_available(); print(torch.cuda.get_device_name(0))'
cd "$SUPERMIMIC_HOME"
"$VENV/bin/python" -m pytest -q
"$VENV/bin/python" scripts/train_velocity.py --help
```

上游 25 项测试曾通过；这不代表任务行走合格。新机器还必须执行下一章的真实烟测。首次运行 Warp/torch.compile 会编译，初始化时间不能当训练卡死；看真实进程、日志增长和 GPU 后再判断。

## 5. 资源校验与归档

```bash
cd "$ROB2NAV"
sha256sum skills/supermimic/checkpoints/velocity_blind_flat_v1_model_12000.pt
python3.12 skills/supermimic/verify_resources.py
"$VENV/bin/python" -m pip freeze > "$WORK/installed-packages.txt"
git -C "$SUPERMIMIC_HOME" diff > "$WORK/upstream-local.patch"
```

检查点 SHA-256 必须为 `ff33dd0140f12a44705632753825be479cb09ba8f5fff737527315f401a51766`。模型、实际配置、overlay 哈希、评估原始 JSON 一起保存；仅有 actor 文件无法恢复世界模型和优化器。

历史证据内保留原机器路径用于溯源，不是本章操作命令，也不要求新服务器创建同样的根目录。
