## 2. 新建训练链路与验收工具

训练表单从同一份类型化schema生成技能参数：前/后翻方向与逐物理步接触峰值、左右翻方向与参考文件、边界连续混合/消抖/子步约束、静态直立与原地交替踏步的互斥及依赖。服务端生成允许列表内的命令，保存实际配置与完成记录；未完成验收的训练产物明确标记`capability_verified=false`。

原地踏步验收使用真实足端碰撞区域，膝部/腿部撑地不能冒充足端支撑。2–5秒每个后足至少3次合格抬脚再落地、至少4次交替，稳定姿态和后足支撑≥95%，漂移≤0.10米、相邻目标步长≤0.08rad；还须完整首尾FIXSTAND、无机身接地、逐物理步速度/限位通过。

四种子评估脚本现支持自己的源码缓存。侧翻必须显式指定与训练哈希/方向相同的参考，避免右翻误用默认左翻轨迹：

```bash
source scripts/docs_env.sh
# 先设置RUN为本次已完成训练目录；MOTION为该任务实际参考NPZ
"$CPU_PY" scripts/evaluate_fixstand_run.py --kind sideflip \
  --run "${RUN:?请设置完成训练目录}" --motion "${MOTION:?请设置本任务参考}" --seed-start 20100
# 原地踏步示例（另一个RUN，使用零位移指令与专用足端验收）
"$CPU_PY" scripts/evaluate_fixstand_run.py --kind upright_step \
  --run "${RUN:?请设置完成训练目录}" --seed-start 20300
```

这些示例会执行真实仿真。使用新输出目录；同一训练目录的既有导出/验收不得悄悄覆盖。右翻用独立20200–20203，前翻20000–20003；不能用训练或选模种子充当独立验收。
