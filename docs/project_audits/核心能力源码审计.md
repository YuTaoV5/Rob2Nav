## NJU agility

[Source](https://github.com/NJU-RLC/quadrupedal-agility/tree/15d16ea99bc23e5d401b0b0e3b88a8edcc28f0ed), [official project](https://nju-rlc.github.io/quadrupedal_agility/). MIT at root; inherited BSD notices in individual files must be preserved.

BBC is semi-supervised generative adversarial imitation learning from dog mocap; categorical latent controls walk/pace/trot/canter/jump, continuous latent controls style. TSC teacher uses privileged information, student uses depth. EASI simulator identification is linked separately to https://github.com/BlackVegetab1e/EASI. These are actual released training/deployment pipelines, not just a paper reference.

Training: `bbc/legged_gym/scripts/train.py --task go2_locomotion --experiment_idx 0 --device_id 0 --headless True`; saves `bbc/logs/go2_locomotion/0/model.pt`. TSC: `tsc/legged_gym/scripts/train.py --proj_name agility --exptid base --device_id 0 --randomize_start --randomize_base_mass --randomize_base_com --push_robots`; student adds `--exptid dist --resume --resumeid base --use_camera`. BBC model copied into `tsc/weights/bbc`; logs in `tsc/logs/agility/{base,dist}/model.pt`.

`go2_deploy` is present and released. Policy entrypoints: `python3 -m go2_deploy.scripts.deploy_policy_with_controller_{2,3,5}`, `deploy_policy_with_depth_cruft`, `deploy_policy_with_depth_hurdle`. Box-depth entrypoint is placeholder: matching models absent. Present model defaults: `models/ll_policy/{2_model,3_model,5_model,hurdle}/model.pt`, `models/high_policy/{cruft,hurdle}/model.pt`, `models/recover_policy/1_model/model.pt`. Low checkpoints require `actor_critic`, `estimator`; high require `estimator_state_dict`, `depth_encoder_state_dict`, `depth_actor_state_dict`.

Contract: Python inference → LCM `pd_plustau_targets` joint PD targets → external `lcm_position_go2` Unitree SDK2 bridge; observations `leg_control_data`, `state_estimator_data`, `rc_command`. Bridge/SDK2/build environment external, recommended https://github.com/BlackVegetab1e/Leggedgym-Deploy-Docker. 12 low-level joint actions. High-level config has 3 discrete gait categories, 6 continuous outputs (5 commands + epsilon), 10-frame proprioception history; depth resized 87×58, buffer 2, update interval 5. Exact mode/normalization differs by config; do not substitute a universal policy interface.

## RoboGauge versus MoE-CTS

[Evaluator source](https://github.com/wty-yy/RoboGauge/tree/add2c7ee0185ea8fd93d242f86e1c8cac6e9913b), MIT. It evaluates locomotion policies in MuJoCo; it is not the source of the MoE training algorithm. Entry `robogauge.sh` → `robogauge/scripts/run.py`; supports single/multi/level/stress pipelines and server/client asynchronous evaluation. Example `./robogauge.sh --task go2_moe.flat --experiment-name debug --headless`; server `./robogauge.sh --server`. Eight metrics: dof limits, linear/angular tracking errors, dof power, orientation stability, torque smoothness, friction margin, ZMP margin. These are normalized higher-is-better proxies, not hardware certification.

Go2 adapter: `robogauge/tasks/robots/go2/go2.py`, `go2_moe.py`, associated configs; `base_robot.py` calls `torch.jit.load`. 45 current observations, 50 Hz / control_dt .02, 12 output actions reordered to MuJoCo joints; position target = action×.25 + default position. Model reset clears history. MoE exported forward returns `(action, results)` where tuple may contain student weights, actor weights and latent. Includes `resources/models/go2/go2_moe_cts_137k_0.6739.pt`, `go2_moe_cts_124k.pt`, `go2_moe_cts_8experts_2cmd_100k.pt`, `go2_cts_max2_100k.pt`.

Local `vendor/moe_reference/PROVENANCE.md` pins historical trainer 30e74dc507bec7a642a8c98be26081f2c6f0822d. Initializer artifact SHA256 2206659a6a23886446dcfc05d86888d6cdc9b8a4e31f44cbbc4e2d17ba3d6ead, 5×45 history, 8 latent experts, 32 latent values, shared actor. This exported artifact lacks original teacher/critic/optimizer/RNG/environment state and does not restore the old training run.

Current original trainer [go2_rl_lab](https://github.com/wty-yy/go2_rl_lab/tree/5702ff7704c53e0b92e69876dc8da25153d36a25) is a substantial upstream migration: Isaac Lab 3.0 EA / Isaac Sim 6.1 / Newton MJWarp; Python 3.12. Entry `./go2_rl_lab.sh --train --task go2-mixed-moe-cts`; code `source/rsl_rl/rsl_rl/moe_cts/algorithm.py`, `runner.py`, `modules/{actor_critic,moe}.py`; privileged teacher + eight-expert student, 3:1 teacher/student env split. Export via `--play`, deployment `--deploy-mujoco --policy exported/policy.pt`; hardware C++ external https://github.com/wty-yy/unitree_cpp_deploy/tree/go2. The old artifact and current trainer need version-specific adapters, not claimed drop-in compatibility. Current source LICENSE retained locally in audit folder.

## AME: G1, Go2, map modality and availability

[SII reproduction](https://github.com/SII-FUSC/AME_Locomotion/tree/1d3519ee946c846c1c89dd660539a224f99972b5) is explicitly G1 29DoF, not Go2. Network `rsl_rl/rsl_rl/modules/actor_critic_encoder.py`: CNN over XYZ map, downsampling, multihead attention fusing local terrain with proprioception, optional global max-pool context. Includes `pretrained/ame1.pt` (33×21 map, CNN downsampling) and `ame2.pt` (attach_global=True). Train `run_train.sh` → `python scripts/rsl_rl/train.py --task AME-G1-29DOF-v0 --max_iterations 15000 --headless`; play task `AME-G1-29DOF-Play-v0 --checkpoint pretrained/ame1.pt`. Stage 2 toggles `FINETUNE=True` in `.../29dof/velocity_env_cfg_29dof.py`. No audited hardware deployment entrypoint. README itself inconsistently says Isaac Sim 5.1.0 Chinese / 5.0.0 English; Isaac Lab 2.3.0 agrees. Preserve discrepancy.

[Go2 adaptation](https://github.com/criticaldamped/AME_Locomotion/tree/15d02c891273d3f4c9b55c9afe3073bcd2d9152f), [detailed official docs](https://github.com/criticaldamped/AME_Locomotion/blob/15d02c891273d3f4c9b55c9afe3073bcd2d9152f/docs/GO2_AME.md): independent Go2 tasks `AME-Go2-Stage1-v0` → `AME-Go2-Stage2-v0`; train/play entry `scripts/go2/run.py --mode train|play`. Stage1 rough/stairs/slopes/boxes/stones/gaps, Stage2 sparse pillars/bridges/wider gaps/rails. Stage transition `--warm_start` transfers full network and resets optimizer/course; same-stage `--resume` restores optimizer etc and rejects cross-stage resumption.

Go2 observation contract documented: yaw-frame 33×21×3 XYZ terrain map plus 45 actor / 48 critic proprioceptive observations; raycast-generated terrain map, not a deployable monocular/depth-camera perception pipeline. Known map geometry is privileged simulator exteroception even if supplied to actor. Distinguish this from NJU depth student. Commands fixed initial +x, forward .3–.8 m/s, no lateral/yaw, 5% standing in training. Policy source `rsl_rl/rsl_rl/modules/go2_actor_critic.py` and tasks `.../go2/stages.py`, `complex_terrains.py`.

Crucial readiness: official Go2 docs say bounded smoke training only (4+4+2 iterations), no formal convergence training. Reported complex tests remained near spawn, negative tiny displacement, no obstacle traversal. Therefore register trainable experimental Go2 AME scaffold; do not label working Go2 obstacle checkpoint. G1 released weights are not Go2 weights. No direct AME demo MP4/GIF located in inspected official READMEs.

License: both AME repositories have no root LICENSE in recursive API trees, GitHub API license=null. They contain RSL-RL subcomponent LICENSE and dependency notices; criticaldamped includes Unitree Go2 asset LICENSE. These do not establish a blanket license for all custom AME code. Record project-level license as unspecified, retain subcomponent notices and require provenance resolution before redistribution.
