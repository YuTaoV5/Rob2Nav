## 结论

- 最快验证 Go2 真实策略推理的是 go2_PIE 已提供的 ONNX + 原生 MuJoCo runtime；服务器已有 IsaacLab 不代表能运行其 MJLab，也不代表能运行 WMP 的 Isaac Gym。
- PIE 当前代码只有平地、上楼梯、下楼梯。不能把论文跨沟/跨障碍结果算作该 Go2 checkpoint 的已验证能力。
- WMP 最强复用项是 Warp 深度渲染、带状态的端到端 TorchScript 导出、Go1 的 MuJoCo/Gazebo/RealSense 部署链；移植到 Go2 或 IsaacLab 需要资产、控制合同和环境接口适配。

## go2_PIE

提交 `fb0db87924a9731913ad1011381c01db6945a9c8`，仓库 https://github.com/WwWv0v/go2_PIE 。

证据：`deploy/pie/sim2sim/contract.py`、`src/tasks/pie/config/go2/{env_cfgs,rl_cfg}.py`、`src/tasks/pie/rl/{pie_model,ppo,runner}.py`、`src/tasks/pie/terrains.py`、`setup.py`。

- Go2，12关节动作，目标位置 `default_q + 0.25*action`；控制50Hz，物理200Hz，深度10Hz。
- 当前本体45维 = 角速度3 + 重力3 + 指令3 + 关节位置12 + 速度12 + 上次动作12。历史10×45=450，**term-major**排列；深度2×60×86（原始60×106，两侧各裁10），范围0.05–3m，除3归一化；GRU隐状态128维。必须保留历史与状态重置。
- 一阶段 PPO + 速度/足间隙/高度重建/后继状态辅助估计 + VAE KL；Transformer融合视觉与本体。Actor MLP512/256/128，PPO lr1e-3、gamma.99、lambda.95、clip.2、5epochs、4minibatches、24steps/env，默认4096env、20000iter、每1000iter保存。
- Python3.11；依赖固定 mjlab1.2.0/mujoco3.5.0/mujoco-warp3.5.0，另有 ONNX Runtime、torchrunx、wandb。训练脚本选择CUDA GPU，视频通过EGL；代码未要求JAX，实际CUDA/驱动兼容性尚未安装验证。
- 已包含 `logs/rsl_rl/go2_pie/model_8000.pt`（11972126字节）和 `policy.onnx`（2628706字节）。根目录未发现许可证；公开可见不等于有再分发授权。

原 README 训练：`python scripts/train.py Unitree-Go2-PIE --agent.run-name stairs`。

源代码推导的短训覆盖（未执行，应先查 --help）：

```bash
python scripts/train.py Unitree-Go2-PIE --env.scene.num-envs 16 --agent.max-iterations 2 --agent.run-name rob2nav_smoke --video --video-length 100 --video-interval 2000
```

保存位置 `logs/rsl_rl/go2_pie/<timestamp>_<run-name>/`；保存env.yaml/agent.yaml；标准父runner的model_*.pt；每次保存还导出同目录policy.onnx。恢复参数 `--agent.resume --agent.load-run <run-pattern> --agent.load-checkpoint <checkpoint-pattern>`，由MJLab get_checkpoint_path查找；不是任意 --path 参数。

播放：

```bash
python scripts/play.py --checkpoint-file logs/rsl_rl/go2_pie/model_8000.pt --viewer viser --network-depth-vis --terrain-level 9 --num-envs 1 --device cuda:0
python deploy/pie/sim2sim/go2_pie_sim2sim.py --checkpoint-file logs/rsl_rl/go2_pie/policy.onnx --provider cpu --terrain stairs --headless --duration 10
```

train默认无窗口，MUJOCO_GL=disable；--video启用EGL和VideoRecorder，写入run/videos/train。play只支持auto/native/viser，无headless/video CLI。原生sim2sim有headless，但没有现成视频录制CLI。

实时关节${HOME} hook：`Sim2SimRuntime.step()`（原生runtime第746行），mj_step后读取data.qpos[root_qpos_adr:root_qpos_adr+7]、data.qpos[joint_qpos_adr]、data.qvel[joint_dof_adr]、last_action/control_step。bindings定义位于91行附近。摄像头输出是optical-Z，contract明确转换到训练使用的ray distance，不能直接互换。

直接GIF（仓库README引用，可img嵌入）：https://raw.githubusercontent.com/WwWv0v/go2_PIE/fb0db87924a9731913ad1011381c01db6945a9c8/docs/go2_demo.gif 。本次clone含该媒体，仅因为源仓库自带，未为展示单独下载。

## WMP Go1

提交 `65cf1afd13e4792bce7b9def6f44372ecbb3cdf0`，https://github.com/haozhang04/wmp_go1 。

证据：`doc/NET.md`、`doc/README_WMP_ORIGINAL.md`、`legged_gym/envs/a1/a1_amp_config.py`、`legged_gym/envs/base/legged_robot_config.py`、`bash/leggedskill.sh`、`rsl_rl/algorithms/amp_ppo.py`、`LICENSE.txt`。

- 虽任务名a1_amp，实际asset是Go1 `go1_new_2.urdf`。AMP配置的动作数据还包含go2_motion目录，跨机器人动作数据必须审查。
- WM10Hz：prop33、depth64×64×1（0–2m，归一化[-.5,.5]）、过去5×12动作、RSSM状态；确定性特征512→64→64→32。
- history50Hz：5帧×42=210 →35（隐变量32+估计速度3）；actor输入70=35+command3+WM32；actor70→256→128→64→12；q_target=default_q+.25action。
- 环境配置num_observations=33+53+187+12=285，包含训练特权信息，不能当作部署actor输入；forward-heightmap525用于深度预测器，不是部署真实相机输入。
- PPO+AMP+Dreamer RSSM世界模型，深度预测器让非相机环境也参与。4100env，其中1100真实渲染；相机backend=warp，update_interval5；dt.005/decimation4。100000iter配置，README建议超过20000；PPO lr1e-3、5epochs、4minibatches、24steps。
- 基础栈明确Isaac Gym Preview3，Python3.8推荐、CUDA11.7 PyTorch安装示例；不是IsaacSim/IsaacLab。Warp只替换深度渲染，未消除Isaac Gym依赖。原版23GB显存要求是原版文档，不能直接归于fork实测。
- Apache2.0根许可证，另有licenses目录；复用需保留第三方许可。训练仓库未发现.pt/.onnx预训练策略。

```bash
CUDA_VISIBLE_DEVICES=0 ./bash/leggedskill.sh -t
CUDA_VISIBLE_DEVICES=0 ./bash/leggedskill.sh -t --resume --path /path/to/model_1000.pt
CUDA_VISIBLE_DEVICES=0 ./bash/leggedskill.sh -p --terrain climb --path /path/to/model_1000.pt --headless
```

Play默认导出端到端TorchScript并录视频；不能把WMP训练checkpoint与最终部署.pt混用。

## 原PIE论文与fork边界

本地2408.13740v3即《PIE: Parkour with Implicit-Explicit Learning Framework for Legged Robots》。原实验机器人是DEEP Robotics Lite3，D435i、RK3588；不是Go2。论文训练Isaac Gym4096env，称4090训练10000iter不到20小时；该结果不能当作MJLab fork性能保证。论文50Hz动作/10Hz深度，45本体观测、12动作。论文涵盖最高1m gap/.75m step/.75m hurdle/.25m stairs，当前Go2仓库仅楼梯和平地。

论文提供官方补充YouTube：https://youtu.be/XsjFNcND6js （可用 https://www.youtube.com/embed/XsjFNcND6js 作为iframe目标；未测试播放）。WMP是另一篇论文2409.16784，不要与2408.13740混同。
