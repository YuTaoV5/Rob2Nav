# AS2-W r249 平地低速姿态预览版

这是面向实机遥控低速平地移动的预览交付，不是楼梯交付版。它优先修复约 0.1 m/s 动态遥控时后腿后倾、后小腿接近地面的问题。r249 重新训练权重的楼梯回归为 0/16，因此不得用于盲走楼梯；现有楼梯权重保持不变。

## 文件

- `weights/policy-r249.onnx`：ONNX actor，输入 `float32[1,60]`，输出 `float32[1,16]`
- `weights/policy-r249.pt`：对应 PyTorch 检查点
- `rl_deploy.yaml`：rl_deploy/Unitree C++ 部署契约
- `evidence/onnx-parity.json`：ONNX 与 PyTorch 一致性
- `evidence/flat-posture.json`：低速动态遥控仿真指标

## 60维观测

按以下顺序拼接，控制周期 0.02 s：

1. `cmd_vx_vy_yaw - [0.4, 0, 0]`（3）
2. IMU 机身角速度（3）
3. IMU 投影重力方向（3）
4. 常数 `0.4`（1）
5. `q - default_q`（16）
6. 关节速度（16）
7. 上一帧最终动作（16）
8. `sin(2πt/0.62), cos(2πt/0.62)`（2）

不输入机身实际线速度，也不输入 IMU 原始线加速度。遥控器 `vx/vy/yaw` 必须每帧动态写入，不能再固定为 0.4 m/s。

## 推理后处理

1. 遥控指令建议先做约 0.2–0.3 s 平滑。
2. 运行 ONNX 得到 16 维动作。
3. 当 `hypot(vx,vy) <= 0.20 m/s` 时，把动作索引 `[2,3,6,7,10,11]` 设为 0，使 RL/RR 的 hip、thigh、calf 回到标准站姿。
4. 把后处理后的动作保存为下一帧 `previous_action`。
5. 腿位置目标为 `default_q + 0.35 * action[0:12]`；轮速目标为 `16 * action[12:16]`。

默认关节顺序与 `rl_deploy.yaml` 一致。实机首次运行应悬空或上架，确认编码器方向、零位、IMU 坐标和急停后再落地。

## 已验证结果

在 8 个低速动态遥控仿真种子上，相对 r242 基线：

- 后腿平均关节偏差：0.220 → 0.179 rad
- 后腿偏差 95 分位：0.593 → 0.344 rad
- 机身 pitch 95 分位：18.1° → 14.1°
- 非轮部件触地控制步：21 → 1
- 提前终止：1/8 → 0/8
- 平面速度跟踪误差：0.272 → 0.189 m/s

ONNX 在 128 组随机输入上相对 PyTorch 的最大绝对误差为 `7.15e-7`。
