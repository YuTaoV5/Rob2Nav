## 2. ⭐ 三条判断

**(a) 转向方向是对的，问题在幅值。**
四个纯转的**有符号偏航跟踪全部为正**（+0.66 / +0.75 / +1.36 / +1.55），**→ 机器人转的方向与指令一致，没有反向。** 与 Isaac 一致（Isaac 也是同向、只是欠转）。**→ 「两端都朝指令方向转，但幅值分歧」这一判断成立。**

**(b) MuJoCo 上左转严重超调，右转反而欠转。**

| | 左转 | 右转 |
| --- | --- | --- |
| ±0.05 | **1.36**（超调，门槛上限 1.30） | **0.66**（欠转，门槛下限 0.70） |
| ±0.10 | **1.55**（超调） | **0.75**（刚进带内） |

**→ 左右不对称在 MuJoCo 上与 Isaac 方向相反**（Isaac 是右向更差，MuJoCo 是左向超调、右向欠转）。**这使「左右不对称来自策略」这一结论站不住 —— 它在两个仿真器上方向不一致。**

**(c) 更严重的是安全失败，不只是跟踪失败。**
- **3 个用例是 `INVALID_STAGE1`**（支撑 0.387 / 0.447 / 0.747，全部低于 0.95 门槛）
- **turn_left_0.10 出现 51 次非轮触地和一次终止** —— 这是**摔/保护触发**，不是单纯转不够
- turn_right_0.10 在纯原地转时 **vx = −0.0531**（后退漂移）

**→ 纯转在 MuJoCo 上会让机器人失去轮支撑。这是比「跟踪不到 0.70」严重得多的问题**，**也解释了为什么纯转必须先在支撑门槛上站住，才谈跟踪。**

**→ 两端共同通过 6 项：hold、straight×2、brake×2、arc_right。****→ `arc_right` 是唯一两端都通过的转向类用例，也是本轮唯一能在双仿真上站住的转向能力。**

## 4. 结论

1. **armD@1k 维持当前候选**（Isaac 7/11、MuJoCo 6/11，共同通过 6 项）
2. **纯转在 MuJoCo 上先破支撑门槛**（0.387–0.747）并出现 51 次非轮触地 —— **优先级高于跟踪**
3. **左右不对称在两个仿真器上方向相反** → 不能归因于策略的固定偏置，需查**接触/支撑**

## 5. 边界

1. MuJoCo 单次运行，非多种子
2. 未跑 MuJoCo 侧的推扰、负载、时延
3. `INVALID_STAGE1` 的含义是第一阶段（稳定/支撑）未过，不代表第二阶段跟踪未测
4. 未与 armE 对照权重同机对比（对照的 7/11 是历史结果）
