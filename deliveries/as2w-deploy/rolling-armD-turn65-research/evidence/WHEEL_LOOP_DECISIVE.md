# ⭐ 决定性结果：**Isaac 隐式驱动零过冲，MuJoCo 显式 PD 过冲 49 倍**

这是操作员第 1 步要求的「两端隔离执行器」实验的完成结果 —— 两端同条件、同序列、策略完全旁路。

## 1. 实验条件（两端完全一致）

| 项 | 值 |
| --- | --- |
| 基座 | **固定**（每样本强制位姿 + 根速度归零；Isaac 抬到 2.0 m） |
| 轮子 | **悬空无接触** |
| 策略 / 陀螺 / 延迟 / 动作斜坡 / 指令门控 | **全部旁路**（Isaac 径写 articulation，不经 action manager） |
| 序列 | 0 → **+0.5** → 0 → **−0.5** → 0 rad/s，各保持 1–2 s |
| 物理步 / 控制周期 | 0.005 s ×4 = **0.020 s**（MuJoCo 0.000625 ×32 = 0.020 s） |
| 轮端 KD / 力矩上限 | **6.0 / 13.5 N·m** |

## 2. 结果对照

| 判据 | MuJoCo（**显式** `tau=6×(target−dq)`） | Isaac（**PhysX 隐式驱动**） |
| --- | --- | --- |
| 首样本轮速（目标 +0.5） | **+24.5 rad/s** | **+0.5 rad/s（精确等于目标）** |
| 峰值 \|dq\| | **≈100 rad/s** | **0.5 rad/s** |
| **过冲倍数** | **49×** | **1.00×** |
| 符号翻转次数 | **多次**（+24.5 → −100 → …） | **0** |
| 力矩饱和帧占比 | 高（持续顶在 −13.5） | **0.0** |

**→ Isaac 的隐式驱动在一个控制周期内把轮速精确驱动到目标，零过冲、零振荡、零饱和。****→ MuJoCo 的显式 PD 因轮子惯量小而猛烈过冲，然后饱和反向。**

## 3. 这就是操作员要查的「隐式 vs 显式」的实证

| 实现 | 实测行为 | 结论 |
| --- | --- | --- |
| **Isaac（隐式）** | 一步到位、无过冲 | **等效于理想速度源** |
| **MuJoCo（显式）** | 过冲 49 倍、振荡 | **有惯性延迟的 PD** |

**→ 两端轮端回路在本体动力学上不是同一个对象。** 这是第一次有直接、可复现、两端的实测证据。

## 4. 🔴 但立刻产生一个必须解释的反向矛盾

| 场景 | Isaac 轮速 | MuJoCo 轮速 |
| --- | --- | --- |
| **悬空、无载、目标 0.5** | **0.5（完美）** | 振荡 ±100 |
| **整机接地、转向 12 s** | **0.116** | **0.744** |

**矛盾：悬空时 Isaac 跟踪完美、MuJoCo 振荡；整机接地时却反过来 —— Isaac 只有 MuJoCo 的 1/6.4。**

**→ 这说明整机差距\*\*不在轮端回路本身\*\*，而在「有载」这个条件上。** 最可能的机制：

1. 接地后轮子需要克服载荷力矩；若所需 >13.5 N·m，两端都会饱和2. **但隐式驱动的"力矩限幅"是否真的按 13.5 生效，尚需在接地工况下直接读回实际施加力矩**3. 若 Isaac 的隐式驱动在重载下**退化为"尽量满足速度目标"而不严格限幅**，则它应转得更快；反之若限幅生效且无积分，会停在较低速度
**→ 下一步必须做的是：在\*\*接地\*\*工况下同时记录两端的\*\*实际轮端力矩\*\*，而不是只看轮速。**

## 5. 已修正的方法学问题

上一轮我用「稳态末段均值」评这个振荡系统，**对振荡无意义**。本轮改用四项判据：过冲倍数、包络衰减（本轮结果无振荡故未用）、符号翻转次数、饱和帧占比。这些量对两端都有定义、可比较。

## 6. 边界

1. **悬空无载**是刻意隔离条件，结论**只适用于无载轮**，不能直接外推到整机2. Isaac 侧的 `tau_applied` 若 `applied_torque` 不可用则为 None —— 本轮饱和帧占比 0.0 需确认是「真无饱和」还是「读不到」（**下一轮核实**）3. 只跑了 KD=6、目标 ±0.5 rad/s 一档4. MuJoCo 侧重力关闭；Isaac 侧重力保留但基座每样本钉住，两者对轮子等效，但对腿关节不完全等效
