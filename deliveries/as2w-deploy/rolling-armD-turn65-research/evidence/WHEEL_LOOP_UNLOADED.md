# 轮端隔离实验：**探针没坏，是我上一轮误判** —— 无载轮在 KD=6 下剧烈振荡

上一轮我报「探针有 bug，输出不可用」，理由是「施加力矩 0 却有 −29.5 rad/s 轮速，自相矛盾」。**本轮 dump 了原始逐样本数据，确认探针是对的，我的推理错了。**

## 1. 我错在哪

我假设「无载轮不可能在零力矩下保持 −29.5 rad/s」。**这个假设是错的。**实验里我关了重力、轮子悬空、关节 friction/armature/damping 全为 0 → **轮子没有任何阻力**，**零力矩下它可以保持任意转速**。所以「力矩均值为 0 + 轮速均值 −29.5」完全自洽 —— 那是一个**振荡的平均**。

## 2. 原始数据（目标 +0.5 rad/s 段）

| 样本 | 四轮实测 dq（rad/s） | 施加力矩（N·m） |
| --- | --- | --- |
| 第 0 个 | **+24.53 / +24.52 / +24.49 / +24.48** | **+3.0** |
| 第 49 个 | −85.81 / −101.03 / −99.37 / −77.47 | **−13.5（饱和）** |
| 第 99 个 | −87.35 / −78.21 / −95.49 / −85.89 | **−13.5（饱和）** |

**第 0 个样本自洽性验证**：`demand = 6×(0.5 − 0) = 3.0` → 记录 +3.0 ✅ **完全吻合**。说明「算 demand → 裁剪 → 下发 → 记录」这条链是**对的**。

## 3. 真实现象：**无载轮在 KD=6 下是严重欠阻尼的**

- 第 0 个样本轮速已到 **+24.5 rad/s**（目标只有 +0.5）→ 20 ms 内过冲 **49 倍**- 第 49 个样本已到 **−85 ~ −101 rad/s** → **反向过冲到 200 倍**- 之后力矩持续饱和在 **−13.5 N·m**，轮子在正负之间大幅振荡

**→ 力学上合理**：轮子转动惯量很小（约 0.0025 kg·m²），KD=6 提供的阻尼远不足以有载时的稳定性所需的量。有地面接触时轮子被载荷与摩擦拖住，所以整机实验里看不到这种振荡；**一旦悬空就暴露出来**。

## 4. 这个结果为什么重要（不是废数据）

**这正好是操作员要查的「隐式速度驱动 vs 显式阻尼」的最敏感工况：**

| 实现 | 预期行为 |
| --- | --- |
| **我的 MuJoCo（显式）** | `tau = 6×(target − dq)` 再裁剪 → **先猛烈过冲，然后饱和反向** → 实测正是如此 |
| **Isaac（PhysX 隐式驱动）** | 阻尼进求解器隐式求解 → **理论上不应产生这种过冲**，会平滑收敛 |

**→ 如果 Isaac 在同一实验里不振荡，那就直接证实了「隐式 vs 显式」是两端差异的机制之一。****这就是一个可判定的、决定性的实验。**

## 5. 判据必须改为（下一轮）

上一轮我用「稳态末段均值」作判据 —— **对振荡系统无意义**。正确判据：

| 指标 | 含义 |
| --- | --- |
| **峰值/过冲倍数** | 首个峰值 ÷ 目标，衡量过冲 |
| **振荡包络衰减时间** | 峰值包络降到 10% 的时间 |
| **符号翻转次数** | 是否出现反向过冲 |
| **力矩饱和帧占比** | 回路是否长期顶在限幅 |
| 稳态误差 | 仅在有阻尼时才用 |

## 6. 边界

1. **仅 MuJoCo**；Isaac 对应版本尚未写2. 只跑了 KD=6 一档；小目标 0.5 rad/s 已足够暴露问题，更大目标会更剧烈3. 重力关闭、轮子完全无载 —— 这是**刻意**的隔离条件，但意味着结论**只适用于无载轮**，不能直接外推到整机
4. 转动惯量 0.0025 kg·m² 是我从 `tau/角加速度` 反推的，未从模型读回确认
