# 轮地耦合的左右对称性检查：**资产层完全对称，排除几何/材质/参数不对称**

上一轮把「实测对角/差分比 5.6–8.8（参考 2.57）」指向**轮地接触的左右对称性**。本轮逐层核对 USD 与运行中 articulation 的生效值 —— **资产层是对称的**。

## 1. 逐层核对结果

### (a) USD 的轮关节 PhysxJointAPI over —— 四个完全相同

```
over "FL_foot" ( prepend apiSchemas = ["PhysxJointAPI"] ) { }
over "FR_foot" ( prepend apiSchemas = ["PhysxJointAPI"] ) { }
over "RL_foot" ( prepend apiSchemas = ["PhysxJointAPI"] ) { }
over "RR_foot" ( prepend apiSchemas = ["PhysxJointAPI"] ) { }
```
**四个定义逐字相同，无任何左右差异。**

### (b) USD 物理材质 —— **一个都没有**

用 `pxr.UsdPhysics` 遍历整个 stage：

```
带 PhysicsMaterialAPI 的 prim: 共 0 个
```
**→ 轮子与地面都没有物理材质，摩擦完全由默认接触参数决定，左右必然对称。**

（说明：视觉材质 `material_6 / material_10 / material_14 / material_18` 编号不同，但那是**外观**，不参与物理。）

### (c) 运行中 articulation 的四个轮关节生效参数 —— 完全相同

| 关节 | friction | damping | armature | maxVel | maxEffort |
| --- | --- | --- | --- | --- | --- |
| FL_foot | 0.000 | 6.000 | 0.000 | 98.470 | 13.500 |
| FR_foot | 0.000 | 6.000 | 0.000 | 98.470 | 13.500 |
| RL_foot | 0.000 | 6.000 | 0.000 | 98.470 | 13.500 |
| RR_foot | 0.000 | 6.000 | 0.000 | 98.470 | 13.500 |
**→ 四个轮关节逐项相同。**

### (d) USD 变体选择

```
variantSet Physics default=physics
```
默认变体是 `physics`（PhysX），与 `mujoco` 变体互斥 —— **不存在两个物理载荷同时生效**。

## 2. 结论

| 层次 | 是否左右不对称 |
| --- | --- |
| 轮关节 PhysxJointAPI | ❌ 否（逐字相同） |
| 物理材质 / 摩擦 | ❌ 否（**根本没有物理材质**，用默认值） |
| 关节摩擦 / 阻尼 / armature / 限幅 | ❌ 否（逐项相同） |
| 物理变体 | ❌ 否（唯一生效变体 `physics`） |

**→ 资产与参数层完全排除左右不对称。**

## 3. 那么对角化来自哪里

上一轮的数据指向仍成立，但归因要改：

- **不是**左右轮的几何/材质/参数不同（已证）
- **是**轮子与地面之间**接触实例的动态结果**：同样的参数下，左右轮接触点的**瞬时接触状态**不同  （贴地压力、接触法向、是否处于滑移边缘），于是同样的差分指令产生了不同的对角分量
- 或者：**对角化根本不是接触造成的，而是策略下发时就有的**（下发对角/差分比 2.1 / 0.6，左右本身就不相等），  只是「实测对角/差分比 5.6 / 8.8」把这种不等**放大**了

**→ 关键缺口：追踪器记录的是「上一帧动作 × 16」，不是「逐帧最终下发的轮目标」。****在拿到真正的逐帧下发值之前，无法区分「策略本来就不对称」与「接触把对称指令变成了对角」。**

## 4. 下一步（唯一缺口）

**在动作下发点记录最终的轮目标与最终补偿量**，即：
1. `DelayedGyroVelocity.apply_actions()` 里的 `tgt`（延迟后）与 `tgt + ff/kd`（补偿后）
2. `set_joint_velocity_target_index` 实际收到的值
3. 同一帧的实测轮速与偏航

**有了这三者，才能判定「差分→对角」发生在策略侧还是接触侧。**

## 5. 边界

1. 结论仅覆盖**资产与参数层**；接触实例的动态行为未测
2. 未读回 PhysX 的**接触求解器设置**（摩擦合成模式、接触偏移、restitution）与**地面刚体属性** —— 这些是下一步
3. USD stage 的质量/惯量在 `physics.usda` 变体里，运行时由 articulation 载入；本轮未逐 body 读回
4. 未在 MuJoCo 侧做同样核对
