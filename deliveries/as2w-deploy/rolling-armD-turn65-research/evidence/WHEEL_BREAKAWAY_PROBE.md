# 轮地脱困阈值探针：**本次设计无效**，但给出三条可用结论

按操作员下一步要求「测量轮地滚动阻力/静摩擦阈值」而做的探针。

- 脚本：`runtime/r11_isaac_wheel_floor.py`
- 权重 `armE_support2p0_final.pt`（`4bdf4d26`），种子 7393，站态 2 s，斜坡 6 s 到 2 rad/s
- 方法：策略保持腿部输出，**只把某一轮的目标速度从 0 缓慢升到 2 rad/s**，其余三轮目标为 0
- 原始数据：服务器 `results/eval/wheel-floor-*/wheel_floor.json`（含 300 帧逐轮 trace）

## 1. 🔴 本次设计无效：无法隔离脱困阈值

首轮判定「onset」在 FL/RL/RR 上落在斜坡第一帧，重算时发现原因：

| 轮 | 斜坡前 0.5 s 基线 |dq| 峰值 |
| --- | --- |
| FL | **0.476 rad/s** |
| RL | **0.263 rad/s** |
| RR | **0.355 rad/s** |
| FR | 0.042 rad/s |

**→ 只驱动一只轮时机器人整体会动，其余三轮被带着滚，基线本身就有 0.26–0.48 rad/s。**
**→ 因此「第一次超过阈值」不能解释为「轮地静摩擦脱困」。本次测量作废，阈值仍未测到。**

## 2. ✅ 仍然成立的三条结论（来自同一 trace）

### (a) 目标 2.0 rad/s 时轮子跟得非常好

| 轮 | 目标 2.00 rad/s 时的实测 dq |
| --- | --- |
| FR | **+1.999**（几乎完美） |
| FL | +1.379 |
| RR | +2.777 |
| RL | +1.228 |

**→ 轮执行器在正常速度下没有问题。问题只出现在小目标。**

### (b) 跟踪率随目标增大而改善（以基线最干净的 FR 为例）

| 目标 rad/s | 实测 dq | 跟踪率 | 实测力矩 |
| --- | --- | --- | --- |
| 0.05 | −0.005 | **−10%** | +0.37 |
| 0.10 | +0.017 | 17% | +0.45 |
| 0.25 | +0.063 | **25%** | +0.86 |
| 0.50 | +0.317 | 63% | +0.78 |
| 1.00 | +0.804 | 80% | +0.98 |
| 2.00 | +1.999 | **100%** | +0.32 |

**→ 小目标下轮子严重欠跟踪，大目标下正常。这与「存在一个阻力地板」相容。**

### (c) 力矩可以远超转向工况，但仍未触顶

| 轮 | 本次斜坡 |tau| 峰值 | 占 13.5 N·m |
| --- | --- | --- |
| **FR** | **10.11 N·m** | **75%** |
| FL | 4.98 N·m | 37% |
| RL | 4.47 N·m | 33% |
| RR | 3.84 N·m | 28% |

**→ 斜坡能把力矩推到 10.11 N·m（75%），说明轮驱有能力输出更大扭矩；转向工况里只用到 4.36 N·m，是因为那里误差小，而不是被限幅。**

## 3. 与上一轮的联合解释（严格版）

**已实测：**
- 转向工况实测力矩 1–4.36 N·m，触顶比例 0.000
- 小目标（0.05–0.25 rad/s）下轮子跟踪率只有 −10%…25%
- 大目标（≥1 rad/s）下跟踪率 80–100%
- 斜坡能把力矩推到 10.11 N·m

**由此可以说的：** 小指令下的欠跟踪**与「误差小时 kd 律输出也小」这一事实一致**；
kd×(目标−实测) 在误差 0.1–0.25 rad/s 时只有 0.6–1.5 N·m。

**仍然不能说的：**
- ❌ 不能说「已测得脱困阈值为 X N·m」—— 本探针没有隔离出来
- ❌ 不能说「增大轮端增益就能解决」—— 未做单变量验证，且此前的 kd=12 试验出现极限环

## 4. 重设计（下一步，未执行）

要真正隔离脱困阈值，必须让机器人不动：

1. **四轮同时给同向斜坡**（共模），或用固定 stand 姿态 + 外部约束，使基线轮速接近 0
2. 先验证基线满足 |dq| < 0.02 且位移 < 1 mm，否则该次试验作废
3. 斜坡从 0 分档（如每档 0.02 rad/s）并每档驻留 0.5 s，记录逐档的 dq 与力矩
4. 阈值 = 相邻两档之间 dq 由 <0.02 跳到 >0.05 的那一档
5. 左右分开测，以量化左右阻力差

## 5. 边界

1. **仅仿真、单种子、单次试验**
2. 本次探针的「onset」字段**不可用**，已在 JSON 中保留 trace 供重算
