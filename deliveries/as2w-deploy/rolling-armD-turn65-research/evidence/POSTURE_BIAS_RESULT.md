# 姿态偏置补偿有效：转弯后站姿残差**减半**（0.198 → 0.104 rad）

## 1. 为什么试这个

前两轮已确认：(a) 转弯后仅保持 fixed stand，误差收敛到 **0.193–0.197 rad** 平台不再改善（负载静态平衡）；(b) **踏步复位没有用**，反而使误差增加 0.025–0.041 rad。因此换用直接对准平衡点的办法：**给站姿目标加一个常数偏置**。

理论依据（线性化 PD 平衡）：

```
目标 DEF 时平衡：  kp*(DEF - q_eq) = tau_load   =>  q_eq = DEF - tau_load/kp
欲使 q = DEF：      target = DEF + tau_load/kp = 2*DEF - q_eq
=> 偏置 bias = -(q_eq - DEF) = 负的实测偏差
```

## 2. 方法

站态 3 s → 策略转弯 12 s → 保持站姿 5 s 并取**末 0.5 s 的平均偏差**作标定值 → 用 `bias = −偏差` 重新保持 5 s → 比较。CPU 侧 MuJoCo，不占 GPU。

- 脚本：`runtime/r11_mj_bias_comp.py`
- 原始：`evidence/mujoco/bias_comp_wz{0.05,-0.05}.json`

## 3. 结果：**残差减半**

| 量 | 左转 wz=+0.05 | 右转 wz=−0.05 |
| --- | --- | --- |
| 转弯结束 | 0.398 | 0.455 |
| **保持站姿（无偏置）** | **0.198** | **0.202** |
| **保持站姿（加偏置）** | **0.104** | **0.115** |
| **变化** | **−0.093（−47%）** | **−0.087（−43%）** |
| 实测偏差幅值 | 0.199 | 0.203 |
| 施加偏置幅值 | 0.199 | 0.203 |

**→ 站姿残差从 ~0.20 rad 降到 ~0.10–0.12 rad，改善 43–47%。**

## 4. 为什么没有降到 0

偏置用的是 `kp*(DEF−q_eq)=τ_load` 的**线性化**，实际系统还有库仑摩擦、接触非线性、腿间耦合与重力随姿态变化，所以**单次偏置只走了一半**。这是可预期的，且指向明确的下一步：

- **迭代偏置**（标定一次 → 应用 → 再测残差 → 再叠加），预期进一步收敛
- 或按各关节分别标定（当前已是 12 维逐关节偏置，迭代即可）

## 6. 边界

1. **仅 MuJoCo、单权重、两种转向方向、单次标定（未迭代）**2. **未验证**：支撑占比、后腿净空、力矩峰值、非轮触地 —— 这些是采用该方案的前置条件3. **偏置依赖负载**：换载荷（如 +6 kg）需重标；负载变化即偏置失效4. 未做偏置在两个方向上的通用性交叉验证（左转标定的偏置用在右转上）
