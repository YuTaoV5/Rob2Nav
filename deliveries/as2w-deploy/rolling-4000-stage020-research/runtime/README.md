# AS2-W 滚动运行时合同记录

策略控制周期为 20 ms。关节顺序为四髋、四大腿、四小腿、四轮，各组为 FL、FR、RL、RR。[逐轴仿真参考](as2w-official-reference.json) 提供 URDF 轴、站姿和仿真角度与力矩保护。实机 DDS 槽位、符号、零位及执行器模式仍待逐轴核对。

| 零基索引 | 训练侧定义 |
| --- | --- |
| 0–2 | 机体系命令 vx−0.4、vy、wz，单位 m/s、m/s、rad/s |
| 3–5 | 机体系 IMU 角速度，rad/s |
| 6–8 | 机体系单位重力方向 |
| 9 | 常量 0.4 |
| 10–21 | 腿关节角减 fixed stand 参考角，rad |
| 22–25 | 轮轴角偏差，按 4π 周期映射到 [−2π, 2π) |
| 26–41 | 16 路关节角速度，rad/s |
| 42–57 | 上一帧包装后的归一化动作，位于接管混合与执行器延迟之前 |
| 58–59 | 以回合计时计算的 0.62 s 周期正弦和余弦 |
| 60–63 | 零速轮角相对参考的回绕差除以 0.20 rad，限幅 ±3，运动时归零 |
| 64 | 三轴命令严格为零的标记 |

回合 reset 清空动作历史并刷新传感器历史。零指令捕获轮角参考。expanded 仿真含 0/1 控制帧观测延迟与 2% 整帧保持，实机数据龄与缺测处置待验证。离线诊断发现实机回放与仿真在腿角偏差字段上差异明显，须在闭环前核对索引、方向、零位和参考角减法。

动作经过 ±6 限幅，腿残差 5 Hz 一阶滤波，轮残差旁路。运动门控和轮速反馈、站姿补偿、轮位锁定随后生效。腿目标角限速为 0.9 rad/s，腿位置动作缩放 0.35 rad，轮速动作缩放 16 rad/s。可核对 [滤波与限速 C++ 离线夹具](filter-parity/README.md) 及两套仿真的实际评估开关。完整 C++ 动作包装、增益、数据龄和 ARM64 影子链路待补。该目录没有实机下发入口。

仿真流程覆盖 fixed stand 进入、运动、松杆减速、轮位保持和末段 fixed stand 判定。训练和评估记录用于校核状态切换，实机控制权、首帧和失联处理仍待验证。
