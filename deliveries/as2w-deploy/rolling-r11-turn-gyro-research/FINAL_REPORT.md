## 2. 双仿真分歧的机制（结论）

| 项 | MuJoCo | Isaac |
| --- | --- | --- |
| 端点通过数 | **7/11**（5 站态复现） | **6/11**（双种子复现） |
| 纯转失效原因 | **四轮支撑**（0.487–0.927） | **偏航**（0.01–0.39），支撑恒 1.000 |
| 轮差交付 `exec` | 0.86–1.04 | 0.25–0.67 |

- Isaac 轮驱**不是力矩受限**：13.5 N·m 上限下峰值仅 4.47 N·m，触顶比例 **0.000**。
- 但存在**小指令死区**：0.064 rad/s 时 kd 律已需 2.95 N·m；目标到 2.5–3.4 rad/s 时 exec 才升到 0.67。
- 提高反馈上限（4→8 N·m）**不改善左弧**（0.50→0.47），且会把四轮支撑压到 0.840。

## 3. 唯一被验证有效的包装改动（gyro-1）

```
tau_ff = S × clamp( yaw_kp × (wz_cmd − wz_meas), ±ff_cap )
S = (−1, +1, −1, +1)   # FL,FR,RL,RR → 左右差速
sp = dq + tau_ff / kd  # 执行器仍按 ±13.5 N·m 硬限位 clamp
```

- 参数：`yaw_kp = 60 N·m/(rad/s)`、`ff_cap = 4 N·m`、无开环前馈。
- 无积分、无滤波（每策略步 4 次子步调用不会复合）；**仅作用于四轮**。
- **指令 `wz = 0` 时前馈严格为 0**，故驻停/直线/刹停按构造不受影响。
- **效果**：Isaac 从 5/11 → **6/11**（`arc_right` 两种子均转 PASS），零终止。
- **回退**：`--yaw-kp 0` 即回到未改控制器。
