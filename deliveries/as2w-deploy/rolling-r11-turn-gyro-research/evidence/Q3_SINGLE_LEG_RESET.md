# Q3 单腿复位：**我的实现失败了** —— 没抬起轮子，还把机身偏航打乱

操作员第 3 问要求：从左右各一个**最差停稳初态**做单腿复位，记录抬腿前三足支撑余量、摆腿最低净空、落地后轮载、机身附加偏航；先在 MuJoCo 验证再用 Isaac 同口径复跑；并要固定俯视+落点/支撑三角形标注的录像。

准入条件（操作员明确）：**只有回正会拖轮、碰限或压低净空的案例才做**。第 1、2 问已证明四类普通转向不满足，因此本轮候选按最差停态选取：左 = 原地左转（`spin_left`），右 = 右弧。

## 2. 🔴 必须分清「已确证」与「是我的实现问题」

**(a) 已确证的事实**
- **抬腿前三足支撑余量只有 1.4–2.0 cm** —— 单腿抬起前的稳定性余量本身就很薄- 我这次的单腿动作**把机身偏航打乱 16–29°**，并在原地转工况造成**两条腿卸载**

**(b) 属于我实现问题的部分（不能归咎于方案本身）**
- **摆腿最低轮高为负（−0.02 ~ −0.03 m）：轮子根本没被抬起，而是被压下去了。**  原因是我用**关节角直接加偏移**（`[0, −0.35, +0.55]` 加到 hip/thigh/calf）当作抬腿，  这**不等于**足端垂直抬升 —— 需要**足端位置的逆解**才能保证轮心向上。- 因此「偏航被打乱」很大程度是**这个错误抬腿轨迹**造成的，**不能据此判定单腿复位不可行**

**→ 结论措辞必须准确：本轮**没有**证明单腿复位不可行，只证明了**我这个用关节偏移实现的版本失败**，并且测到了一个有价值的前置事实：**三足支撑余量仅 1.4–2.0 cm**。

## 3. 这对「需不需要抬腿」的最终影响

结合第 1、2 问：

| 问题 | 答案 |
| --- | --- |
| 偏差在落点还是只在关节角 | **在轮心落点** |
| 什么时候出现 | **转弯阶段（松杆前）**，不是回站时 |
| 回站是否改善 | **是，70–89%** |
| 四类普通转向需要抬腿吗 | **不需要** |
| 真要抬腿时余量够吗 | **三足支撑余量仅 1.4–2.0 cm，很薄** |
| 我的单腿复位实现可用吗 | **不可用（没抬起来，打乱偏航）** |

## 4. 要重做的话，最小改动是什么

1. **用足端逆解抬腿**，而不是给关节角加偏移；以「轮心相对机身向上 `lift_m`」为目标反解 hip/thigh/calf2. 抬腿期间对另外三腿做**支撑补偿**（保持机身高度与水平），否则偏航与滚转必然被打乱3. 抬腿高度先取小值（如 0.03 m）配 1.4–2.0 cm 的薄余量，先证明能抬起再谈复位4. 之后才做「落到目标落点」与录像（固定俯视 + 当前落点/目标落点/支撑三角形标注）
