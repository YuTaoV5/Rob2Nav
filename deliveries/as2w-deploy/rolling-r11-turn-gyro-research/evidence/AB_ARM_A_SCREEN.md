# A 组（等预算 1,000 轮）首轮快筛：**通过数不变，转向普遍退化**

操作员第一轮要回答的问题：「稳定直行和刹停能不能保住，以及左右转最弱的一侧在第 3–5 秒以后能不能继续转。」

## 1. 结果

**A 组 `model_5500`（`4bdf4d26` 续训 1,000 轮、gyro 在闭环内），种子 7393，同一冻结矩阵：**

| 用例 | 对照 `4bdf4d26` | **A `model_5500`** | 变化 |
| --- | --- | --- | --- |
| hold | PASS | PASS | 保持 |
| straight_fwd 0.25 | PASS | PASS（跟踪 0.86） | 保持 |
| straight_bwd 0.25 | PASS | PASS（跟踪 0.85） | 保持 |
| brake_fwd | PASS | PASS | 保持 |
| brake_bwd | PASS | PASS | 保持 |
| **arc_right 0.25** | PASS 0.78 | PASS **1.27**（逼近 1.30 上限） | 更好但**接近超调** |
| **turn_left_0.05** | FAIL 0.39 | FAIL **0.04** | **显著变差** |
| **turn_right_0.05** | FAIL 0.35 | FAIL **0.12** | **显著变差** |
| **turn_left_0.10** | FAIL 0.18 | FAIL **0.02** | **显著变差（最差）** |
| turn_right_0.10 | FAIL 0.29 | FAIL 0.25 | 略差 |
| **arc_left 0.25** | FAIL 0.50 | FAIL **0.33** | **变差** |
| **合计** | **6/11** | **6/11** | **不变** |

## 2. 结论（逐项回答操作员的问题）

| 问题 | 答案 |
| --- | --- |
| 稳定直行能否保住 | ✅ **保住**（前进 0.86、倒车 0.85，均 PASS） |
| 刹停能否保住 | ✅ **保住**（前后刹停均 PASS，末段近零） |
| 驻停能否保住 | ✅ **保住** |
| **最弱侧转向第 3–5 秒后能否继续转** | ❌ **没有改善，反而更差** |

**最弱侧（`turn_left_0.10`）从 0.18 降到 0.02；左弧从 0.50 降到 0.33。**
唯一变好的是右弧（0.78 → 1.27），但它已逼近 1.30 超调上限，属**脆弱改善**。

## 3. 判定

**按 goal 的硬约束「只有短对照显示双向转向可重复改善，才可扩到万轮训练」：**

- A 组**没有**带来双向改善（左侧显著退化，右侧仅弧线单项变好且逼近上限）
- 通过数与对照相同（6/11），**未达到阶段 B 的任何要求**
- **→ 不建议沿 A 组路径扩到 4,000 轮**；应转 B 组（长转课程）或按 §3 的失败环节选下一改动

## 4. 边界

1. **仅 1 个种子（7393）的快速筛**，按标准入围后才做双种子留出复测
2. 只筛了 `model_5500`；`model_4600`–`5400` 未逐一快筛
3. 训练其余超参、奖励、采样与 armE 完全一致（等预算对照的定义）
