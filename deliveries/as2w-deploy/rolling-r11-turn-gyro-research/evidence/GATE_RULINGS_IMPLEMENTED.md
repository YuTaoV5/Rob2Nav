## 1. 短暂卸载（四轮滚动）

| 项 | 口径 |
| --- | --- |
| 判定粒度 | **按单轮**、连续卸载时长，**20 ms 采样** |
| 短暂卸载 | **1–3 个连续卸载样本**（≤60 ms） |
| 支撑失败 | **第 4 个连续样本起**判该工况支撑失败 |
| 严重失支撑 | **200 ms** 作为诊断分档（**不是**失败线） |
| 附带报告 | 每轮**累计卸载时长**、**最长连续时长**、**最少同时承重轮数** |

沿用冻结矩阵的承重判据（20 N）；**两端先核对接触信号采样口径**（待办）。

## 2. fixed stand

| 项 | 口径 |
| --- | --- |
| 参考 | 冻结的站姿参考角 |
| 判据 | **12 个腿轴最大绝对误差 ≤ 0.10 rad，连续保持 ≥ 1 秒** |
| 同 1 秒内还需满足 | 四轮承重、无非轮触地、驻停速度门槛、力矩预算 |
| 未满足 | 记**回站失败**，并记录**轮心残差**及其对**再次起步**的影响 |
| 失败基线 | 当前约 **0.19 rad** 的平台**保留**为失败基线 |
