# 轮端低速能力的结论：**「脱困阈值」这个提法不成立**，但边界已收窄

这是本主题的**收尾文档**。四次探针（两次单轮、两次共模、其中一次机体锁定）都没有给出
一个可用的「脱困力矩阈值」，原因不是实现 bug，而是**问题提法本身不适用于滚动轮**。
下面把四次尝试的失败原因、仍然成立的事实、以及收窄后的边界写清楚，并给出后续应当怎么问。

## 1. 四次尝试与各自的失效原因

| # | 设计 | 结果 | 为什么不行 |
| --- | --- | --- | --- |
| 1 | 单轮目标斜坡，其余三轮 0 | VOID（onset 落在第一帧） | 驱动一只轮使整机偏转，其余轮被拖动，基线 |dq| 0.26–0.48 |
| 2 | 四轮共模斜坡，腿跟随策略 | **VOID_BASELINE**（0.3534 rad/s） | 策略仍在动腿，身体位移拖轮 |
| 3 | 四轮共模斜坡，腿冻结 fixed stand | **VOID_BASELINE**（0.4348 rad/s） | kd 速度驱动零目标下是阻尼器不是刹车，机器人持续爬行 |
| 4 | 再加**机体锁定**（每步写回 root 位姿、清零速度） | **VOID_BASELINE**（8.71 rad/s） | **物理上根本错**：机体锁死时轮子无法滚动（滚动需要平移），只能打滑 —— 测到的是打滑，不是滚动脱困 |

**第 4 次的失效最值得记录**：把机体锁住会把滚动接触变成滑动接触，
所以「机体锁定 + 轮速斜坡」在这个问题上**测不到滚动阻力**，这是方法层面的错误，不是参数问题。

## 2. ✅ 仍然成立的事实（第 4 次试验的数据本身很有价值）

机体锁定后，轮子在**打滑**条件下跟踪得非常好：

| 目标 rad/s | 稳态 dq（FL/FR/RL/RR） | 稳态实测力矩 N·m |
| --- | --- | --- |
| 0.02 | +0.025 / −0.212 / +0.028 / +0.016 | −0.05 / +0.20 / −0.07 / +0.89 |
| 0.10 | +0.118 / +0.104 / +0.119 / +0.107 | −0.12 / +0.08 / −0.13 / +0.11 |
| 0.20 | +0.206 / +0.348 / +0.219 / +0.197 | −0.06 / +0.02 / −0.13 / +0.06 |
| 0.30 | +0.316 / +0.306 / +0.312 / +0.299 | −0.10 / −0.03 / −0.09 / +1.09 |
| 0.40 | +0.425 / +0.409 / +0.406 / +0.550 | −0.17 / −0.05 / −0.06 / +0.73 |

**→ 打滑条件下 dq ≈ 目标（0.30 → 0.30–0.32；0.40 → 0.41–0.55），力矩 ≤1.09 N·m。**
**→ 结论：执行器与控制律完全有能力输出 0.1–0.4 rad/s 的小轮速，而且所需力矩很小。**
**→ 这排除了「执行器本身做不到小转速」这一解释。**

## 3. 与自由站立工况并置后，边界收窄

| 条件 | 目标 0.05–0.25 rad/s 时的实测轮速 | 力矩 |
| --- | --- | --- |
| **自由站立**（机器人可动，§105） | dq ≈ 0.00–0.20，严重欠跟踪 | 1–4.4 N·m |
| **机体锁定**（打滑，本节） | dq ≈ 目标，几乎完美 | ≤1.09 N·m |

**→ 差别不在执行器，而在**轮子是否必须带动整机**。**
**→ 因此自由站立下的小指令欠跟踪，本质是：kd 律在误差 0.1–0.25 rad/s 时给出约 0.6–1.5 N·m，
不足以在带动整机的条件下把轮速推上去。**

**收窄后的边界（可作为工作假设，不是测量结论）：**
- 使整机在平地上滚动所需、折算到单轮的**等效驱动力矩**：**> ~1.2 N·m 且 ≲ 4.4 N·m**
- 依据：稳态 dq≈0.01 时力矩 1.2 N·m 仍不能使机器人前进；而力矩达到 4.4 N·m 的工况下机器人确已滚动

## 4. 结论：问题应当怎么问

**「轮地脱困力矩阈值」不是一个适定的量**，因为滚动轮没有单一的静摩擦脱困点；
随速度、载荷和机身姿态变化的是一条**阻力曲线**。正确的问法是：

1. **等效滚动阻力随速度的曲线**：在**让机器人自由滚动**的前提下，扫速度档（0.02/0.05/0.1/0.2/0.4 rad/s），
   每档跑到稳态，记录稳态力矩。这才是可测的。
2. **左/右等效阻力差**：同一条件下比较左右两侧的稳态力矩。
3. **随载荷变化**：在 0 / +6 kg 下重复上述曲线。

第 1 条的可行性已由本节数据支持：只要机器人能自由滚动，稳态力矩就是有限且可读的。

## 5. 边界与诚实声明

1. **四次探针全部无效**，`onset` 字段一律不可用；本文件不提供任何阈值数字
2. 第 2 节数据来自一次 VOID 试验的**打滑**条件，只用于排除「执行器做不到」，**不能**当作滚动阻力
3. 第 3 节的 1.2 / 4.4 N·m 是**跨试验推得的边界**，口径不完全统一，只能作工作假设
4. 仅仿真（Isaac/PhysX）、单种子
