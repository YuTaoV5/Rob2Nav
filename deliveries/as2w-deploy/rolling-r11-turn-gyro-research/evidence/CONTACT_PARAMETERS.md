# 接触参数读回（操作员要求）：两端**生效值**

「Isaac Lab 记录四轮和地面材质及组合模式，MuJoCo 记录接触对的 `friction` 和 `dim`；两端用各自的**生效值**比较，`f=1.2` 留在敏感性测试中。」

## 1. MuJoCo 3.2.3

### 声明值与生效值不是一回事

| 项 | 值 |
| --- | --- |
| 地面 geom 声明 `friction` | **0.620 / 0.00500 / 0.00010**（滑动/扭转/滚动） |
| 地面 geom `condim` | 3 |
| **站立时实际接触对的 `friction`** | **1.000 / 1.0000 / 0.00500** |
| 接触对 `dim` / `condim` | **3 / 3**（全部 11 个接触对一致） |

**→ MuJoCo 的摩擦合成规则是取各分量的 max，轮体一侧为 1.0，所以生效滑动摩擦是 1.0，不是地面声明的 0.62。**

站立时 11 个接触对全部为 `geom ground(0) <-> 各连杆 geom`，`dist` 在 −0.0146 … −0.0001 m，每个接触对的 `dim=3`、`friction=(1.000, 1.0000, 0.00500)` 完全一致。

## 3. 🔴 对 §112 的更正

`evidence/FRICTION_SENSITIVITY.md` 曾写「MuJoCo 地面 0.62 vs Isaac 1.0，两端从未统一」。**该表述不准确**：0.62 只是 MuJoCo 地面的**声明值**，而**生效接触摩擦是 1.0**（max 合成），与 Isaac 轮体的 1.0 **实际上是一致的**。

因此：
- **不能**再说「两端摩擦标称不一致」
- §112 的 f=0.62 扫描**并不是**「对齐 MuJoCo」，而是把 Isaac 的摩擦**降到低于** MuJoCo 生效值
- §112 仍成立的部分：**结果对摩擦高度敏感**（arc 在 f=1.2 双过、在 f=0.62 双不过），这一点与「哪个值是 MuJoCo 的真值」无关

**尚未对齐的项**：MuJoCo 的**扭转摩擦 1.0** 与**滚动摩擦 0.005** 在 Isaac 侧没有对应读数，PhysX 的合成模式也未知。**因此「两端摩擦完全一致」尚不能宣称**，只能说滑动分量的生效值相同。
