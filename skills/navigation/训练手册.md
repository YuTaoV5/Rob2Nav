# Go2 PPO目标导航训练手册

## 1. 目标与当前边界

SCAN是经典规划器，不训练SCAN权重。此处只训练可选的PPO导航速度头，底层保持RoboGauge运动策略；两者不是同一算法。网站当前选择哪一后端，以页面状态和模型哈希为准。

## 2. 环境与前置条件

本手册使用Linux Bash；先完成[环境准备与路径约定](../../docs/环境准备与路径约定.md)。每个新终端在仓库根目录运行`source scripts/docs_env.sh`。变量只表示你自己的安装位置，不依赖原服务器。

本项PPO导航训练使用CPU MuJoCo环境。

## 3. 准备输入文件

```bash
test -f skills/navigation/config.json
test -f vendor/RoboGauge/resources/models/go2/go2_moe_cts_137k_0.6739.pt
export MUJOCO_GL=egl
"$CPU_PY" -c 'import mujoco,torch,stable_baselines3; print(mujoco.__version__,torch.__version__,stable_baselines3.__version__)'
```

每个`test -f`都应成功，缺文件时按总览获取，不能复制原服务器的绝对路径。

## 4. 先烟测，再正式训练

烟测用于确认模型、数据和保存流程接通，不用于证明收敛：

```bash
"$CPU_PY" -m go2_nav.train \
  --config skills/navigation/config.json \
  --sensors lidar \
  --scene empty \
  --envs 1 \
  --steps 512 \
  --seed 42 \
  --output outputs/reproduction/nav_smoke01
```

核对下节的实际输出，再启动正式预算；输出目录已存在时换新名字：

```bash
"$CPU_PY" -m go2_nav.train \
  --config skills/navigation/config.json \
  --sensors lidar \
  --scene random \
  --envs 4 \
  --steps 100000 \
  --seed 42 \
  --output outputs/reproduction/nav_run01
```

## 5. 输出与验收

确认`navigation.zip`、`manifest.json`与`navigation_config.json`。PPO按rollout取整，实际步数以保存清单为准；273维观测与3维速度动作不能套用运动层权重。

完成训练后按仿真手册验收固定模型。至少独立四种子，记录失败；新训练不承诺与历史权重逐位相同。

## 6. 常见问题与下一步

找不到模块：确认当前目录为仓库根目录，并source环境文件。找不到解释器：核对`CPU_PY`与`ISAAC_PY`，二者不能混用。输出目录已存在：换一个新目录，不删除旧实验。显存不足：降低环境数，并把改变后的参数保存到新实验记录。

每次保留原始命令、实际配置、模型SHA256和完整日志；退出码0不等于动作通过。继续阅读[训练手册](训练手册.md)、[仿真手册](仿真手册.md)、[部署手册](部署手册.md)。
