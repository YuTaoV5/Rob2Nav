# Go2 PPO目标导航仿真手册

## 1. 目标与当前边界

本示例使用随仓库发布的PPO导航头。规则导航、PPO、SCAN必须分别记录，不把一种算法的到达成绩给另一种。SCAN复现另看[SCAN仿真手册](SCAN仿真手册.md)。

## 2. 环境与前置条件

本手册使用Linux Bash；先完成[环境准备与路径约定](../../docs/环境准备与路径约定.md)。每个新终端在仓库根目录运行`source scripts/docs_env.sh`。变量只表示你自己的安装位置，不依赖原服务器。

## 3. 选择权重与配置

```bash
export MODEL="$ROB2NAV_ROOT/skills/navigation/policy/navigation.zip"
export CONFIG="$ROB2NAV_ROOT/skills/navigation/policy/navigation_config.json"
test -f "$MODEL" && test -f "$CONFIG"
sha256sum "$MODEL"
```

网页演示：在Studio选择目标导航和实际后端。独立PPO窗口可运行`"$CPU_PY" -m skills.navigation.live --port 8768 --checkpoint "$MODEL" --config "$CONFIG"`，浏览本机8768端口；无需填写原服务器IP。自己的模型需同时换用相同训练的配置快照。

## 4. 执行与观察

```bash
"$CPU_PY" -m skills.navigation.benchmark \
  --checkpoint "$MODEL" \
  --config "$CONFIG" \
  --scene empty \
  --goal 2 .5 \
  --episodes 4 \
  --seed 15300 \
  --output outputs/reproduction/nav_empty01
"$CPU_PY" -m skills.navigation.benchmark \
  --checkpoint "$MODEL" \
  --config "$CONFIG" \
  --scene slalom \
  --goal 7.5 1.6 \
  --episodes 4 \
  --seed 15400 \
  --output outputs/reproduction/nav_slalom01
```

首次回合完成后，再固定同一权重换四个独立种子和新输出目录；不要把调参种子混入独立验收。

## 5. 输出与验收

查看输出目录的`summary.json`、逐步轨迹和原速录像。进入目标0.40m范围后发零速度，继续真实物理积分2秒；全程无碰撞/跌倒，最终距离小于0.55m、水平速度小于0.20m/s。固定布局通过不能推导任意地图可靠。

## 6. 常见问题与下一步

找不到模块：确认当前目录为仓库根目录，并source环境文件。找不到解释器：核对`CPU_PY`与`ISAAC_PY`，二者不能混用。输出目录已存在：换一个新目录，不删除旧实验。仿真黑屏：检查EGL/OpenGL及渲染日志；连接设备前，先核对该机架构、SDK和推理依赖。

每次保留原始命令、实际配置、模型SHA256和完整日志；退出码0不等于动作通过。继续阅读[训练手册](训练手册.md)、[仿真手册](仿真手册.md)、[部署手册](部署手册.md)。
