# Go2 楼梯训练手册

## 1. 目标与当前边界

本方案训练的是感知MoE分支，使用冻结RoboGauge运动基座和已有V2感知初始化；不是重新从零训练运动基座。网站固定场景直接使用原始MoE的演示，与本感知分支实验分开统计。

## 2. 环境与前置条件

本手册使用Linux Bash；先完成[环境准备与路径约定](../../docs/环境准备与路径约定.md)。每个新终端在仓库根目录运行`source scripts/docs_env.sh`。变量只表示你自己的安装位置，不依赖原服务器。

训练必须使用Isaac解释器。运行前查看GPU占用，确认没有同名任务；本手册命令不会自动接管现有训练。

## 3. 准备输入文件

```bash
export MOE="$ROB2NAV_ROOT/vendor/RoboGauge/resources/models/go2/go2_moe_cts_137k_0.6739.pt"
export INIT="$ROB2NAV_ROOT/artifacts/moe_memory_v2_end/training/visible_moe_memory4_v2_seed42/model_999.pt"
test -f "$MOE" && test -f "$INIT"
sha256sum "$MOE" "$INIT"
"$CPU_PY" -m moe_perceptive.check --checkpoint "$MOE" --output outputs/reproduction/model_check.json
```

每个`test -f`都应成功，缺文件时按总览获取，不能复制原服务器的绝对路径。

## 4. 先烟测，再正式训练

烟测用于确认模型、数据和保存流程接通，不用于证明收敛：

```bash
"$ISAAC_PY" -m moe_perceptive.train --headless --device cuda:0 \
 --moe "$MOE" --initialize-from "$INIT" --kind stairs --course original \
 --seed 71 --memory-lifetime 4 --sensor-rig original --numeric-debug \
 --studio-config skills/stairs/studio_config.json \
 --num-envs 32 --iterations 2 --warmup 1 --fusion 1 --actor 0 --output outputs/reproduction/stairs_smoke01
```

核对下节的实际输出，再启动正式预算；输出目录已存在时换新名字：

```bash
"$ISAAC_PY" -m moe_perceptive.train --headless --device cuda:0 \
 --moe "$MOE" --initialize-from "$INIT" --kind stairs --course original \
 --seed 71 --memory-lifetime 4 --sensor-rig original --numeric-debug \
 --studio-config skills/stairs/studio_config.json \
 --num-envs 512 --iterations 200 --warmup 20 --fusion 180 --actor 0 --output outputs/reproduction/stairs_run01
```

## 5. 输出与验收

检查`completed.json`、`model_*.pt`和TensorBoard事件；正式200更新的默认最终文件为`model_199.pt`。更改预算后按实际完成记录选择，不猜测文件名。

学习率由`studio_config.json`显式固定为1e-5；保存该配置哈希。

完成训练后按仿真手册验收固定模型。至少独立四种子，记录失败；新训练不承诺与历史权重逐位相同。

## 6. 常见问题与下一步

找不到模块：确认当前目录为仓库根目录，并source环境文件。找不到解释器：核对`CPU_PY`与`ISAAC_PY`，二者不能混用。输出目录已存在：换一个新目录，不删除旧实验。显存不足：降低环境数，并把改变后的参数保存到新实验记录。

每次保留原始命令、实际配置、模型SHA256和完整日志；退出码0不等于动作通过。继续阅读[训练手册](训练手册.md)、[仿真手册](仿真手册.md)、[部署手册](部署手册.md)。
