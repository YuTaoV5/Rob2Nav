# 三种动作的标准站姿首尾续训

目标是策略自己完成 `标准四足站立 → 动作 → 标准四足站立`。结束时不使用额外固定站姿控制器覆盖策略输出，也不把重置/姿态写入当成恢复成功。

标准站姿与统一部署stand一致：四个hip为0，前腿thigh为0.8，后腿为1.0，四个calf为−1.5rad。训练执行器仍使用各动作的40/1 PD合约；进入统一stand控制器时另做增益过渡，不能把同一关节姿态解释成同一电机增益。

| 动作 | 训练改变 | 策略输入 |
| --- | --- | --- |
| 侧翻 | 原参考前后各加1秒标准站姿，以0.8秒平滑段连接原动作；禁止随机动作相位重置，100%从参考第0帧开始；延长episode覆盖末段 | 保留69维，必须使用新的完整参考NPZ及其哈希 |
| 后翻 | 保留60维原生相位特征；禁止训练器随机初始化episode时钟；前0.35秒加强标准站姿，2秒后强化站姿、静止和恢复，episode延长至4秒 | 保留60维原生后翻合约 |
| 直立 | 100%从标准四足姿态重置；0–1秒站立、1–5秒起立/直立、5秒后恢复、6.5–8秒末段站稳；任务奖励按阶段启闭，安全惩罚始终保留 | 从48维扩为52维：追加起始/动作/恢复三个标志及时间进度；原层权重迁移，新增输入权重初始化为0，优化器重新建立 |

直立52维不能直接放入旧的upright48部署适配器；部署必须按同一时钟产生阶段输入。侧翻旧参考与新参考也不可混用。首次转换后的直立52维检查点可以在相同阶段合约下继续恢复优化器训练。

## 复现和查看状态

准备Isaac环境、固定上游源码和侧翻原始CSV的方法沿用各技能TRAINING.md。CPU环境另需 `onnx==1.17.0`，用于后翻导出与ONNX数值一致性检查。

```bash
cd /root/gpufree-data/Rob2Nav
# 输出目录必须是新目录；以下会实际训练，占用GPU。
PYTHONPATH=$PWD OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=1 \
  /root/gpufree-data/envs/rob2nav-studio/bin/python -m skills.train_fixstand \
  --output outputs/fixstand_reproduce_new --iterations 500 --num-envs 1024

# 可在另一终端运行；训练未完成时等待，每个技能完成后自动导出和评估。
MUJOCO_GL=egl OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  /root/gpufree-data/envs/go2-mapless/bin/python -m skills.evaluate_fixstand \
  --run outputs/fixstand_reproduce_new --wait

cat outputs/fixstand_finetune_20261021/status.json
cat outputs/fixstand_finetune_20261021/evaluation.json
tail -f outputs/fixstand_finetune_20261021/sideflip.log
```

复现侧翻v2时，在上述训练命令加 `--sideflip-boundary-residual`。省略该选项得到第一轮非受限动作合约的对照。两者不能共享未注明版本的部署参数。

阶段失败应先检查对应log，不应覆盖已有输出后反复启动。完整新模型、参考和配置在服务器的新训练目录；只有验收通过后才选择可部署候选。当前提供的是已启动的训练和自动验收流程，不能将运行中的任务描述为三个新权重已经通过。

## 验收

从标准站姿进行完整自由基座MuJoCo积分，不在动作中途重置。首段（侧翻/直立0.1–0.8秒、后翻0.1–0.35秒）及最后连续1秒，至少95%采样须同时满足：

- 12个关节相对标准站姿的最大误差≤0.12rad，最大关节速度≤1rad/s；
- 机身竖直余弦≥0.98，平移速度≤0.1m/s、角速度≤0.5rad/s；
- 四腿有地面支撑。

支撑要求每腿实际接触法向力>4N，机身高度还须位于0.26–0.40m；仅有碰撞几何接近地面不算站稳。

另外必须完成中段动作：翻转动作包含完整旋转、腾空和落稳，直立至少保持1.5秒，且无不允许的身体触地。首尾站着但没有做动作不计成功。额定关节速度、硬限位与硬件资格分别记录；少量仿真种子通过仍不授予实机资格。
