# Go2 前空翻训练手册

## 1. 目标与当前边界

训练Go2从四足站姿完成正俯仰一整周前翻，再回到稳定四足。已有v1独立四种子动作0/4：约束通过但没有起跳翻转，不能发布为合格策略。下面给出可复现的原任务参数，不承诺训练后收敛。

## 2. 环境与前置条件

本手册使用Linux Bash，先完成[环境准备与路径约定](../../docs/环境准备与路径约定.md)，每个新终端先在仓库根目录`source scripts/docs_env.sh`。这是独立正俯仰任务，不能倒放后翻视频或取旋转绝对值冒充前翻。

网站已有前翻配方时，优先在“创建实验”选择frontflip_native_ppo，核对方向front，保存32环境、2更新烟测草稿，预检后在队列提交；再根据实际配置与模型决定正式预算。若新克隆版本尚未包含此网页配方，可用下列模块复现原始任务，不能误选后翻配方。

## 3. 准备输入文件

```bash
export SOURCE="$ROB2NAV_UPSTREAMS/GO2_backflip"
git -C "$SOURCE" rev-parse HEAD
```

提交应为954aa61ceb62c515689677f44a21e32109f6b62d。使用真实Go2形态与60维观测，新建actor；不套Go1/Go2W或69维侧翻权重。

## 4. 先烟测，再正式训练

```bash
"$ISAAC_PY" -m skills.backflip.train_isaac51 --source "$SOURCE" \
  --flip-direction front --fixstand-roundtrip --delayed-entry --entry-hold-scale .1 \
  --urdf-speed-limits --fast-safety-curriculum --safety-start 0 --initial-std .3 \
  --min_action_std .1 --max_action_std .5 --safety_warmup_iterations 100 \
  --safety_ramp_iterations 4000 --seed 49 --trainer rsl_rl --headless --device cuda:0 \
  --num_envs 32 --max_iterations 2 --fixstand-output outputs/reproduction/frontflip_smoke01
```

确认下节的实际配置，再将num_envs设为4096、max_iterations设为5000，输出改为新的`outputs/reproduction/frontflip_run01`。这属于原v1研究任务的复现，不是对失败任务的无依据重复提交；要改奖励或任务目标，先说明假设并保存新配置。

## 5. 输出与验收

必须有模型、completion.json、params/env.yaml、params/agent.yaml和fixstand.json。实际配置应记录5秒回合、1秒入口、hold0.1、方向front与初始std0.3。烟测不等于动作通过，正式完成后仍需正方向整周、首尾站姿、身体接触和逐物理步速度/限位联合验收。

## 6. 常见问题与下一步

默认方向是back，漏掉flip-direction会训练另一个任务；不能只改显示名称。已有上游目录时检查提交，不再次clone覆盖。输出目录已存在时换新名称。继续阅读[仿真手册](仿真手册.md)和[部署手册](部署手册.md)。
