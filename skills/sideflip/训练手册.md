# Go2 侧空翻训练手册

## 1. 目标与当前边界

本流程复现连续参考衔接、安静准备段和物理子步约束的侧翻续训。当前候选仍有翻转段目标突变/超速与落地失败，不保证训练后自动合格；左右翻需分别检查旋转方向。

## 2. 环境与前置条件

本手册使用Linux Bash；先完成[环境准备与路径约定](../../docs/环境准备与路径约定.md)。每个新终端在仓库根目录运行`source scripts/docs_env.sh`。变量只表示你自己的安装位置，不依赖原服务器。

训练必须使用Isaac解释器。运行前查看GPU占用，确认没有同名任务；本手册命令不会自动接管现有训练。

## 3. 准备输入文件

```bash
export SOURCE="$ROB2NAV_UPSTREAMS/GO2_backflip"
export UNITREE_SOURCE="$ROB2NAV_UPSTREAMS/unitree_rl_lab"
export MOTION="$ROB2NAV_ROOT/artifacts/fixstand_best_flips_20261022/outputs/fixstand_finetune_20261021/sideflip.npz"
export PARENT="$ROB2NAV_ROOT/artifacts/unified_backflip_contract_20261022/outputs/fixstand_sideflip_landing_v10_20261022/model_10695.pt"
test -f "$MOTION" && test -f "${MOTION%.npz}.json" && test -f "$PARENT"
sha256sum "$MOTION" "$PARENT"
```

每个`test -f`都应成功，缺文件时按总览获取，不能复制原服务器的绝对路径。

## 4. 先烟测，再正式训练

烟测用于确认模型、数据和保存流程接通，不用于证明收敛：

```bash
"$ISAAC_PY" -m skills.sideflip.train \
  --backflip-source "$SOURCE" \
  --unitree-source "$UNITREE_SOURCE" \
  --motion "$MOTION" \
  --resume "$PARENT" \
  --headless \
  --device cuda:0 \
  --transfer-motors \
  --fixstand-roundtrip \
  --boundary-residual \
  --boundary-residual-limit .20 \
  --boundary-bridge-limit .05 \
  --boundary-terminal-hip-taper-frames 50 \
  --boundary-blend-frames 10 \
  --quiet-preparation \
  --peak-endpoint-objective \
  --landing-constraints \
  --substep-objective \
  --finetune-learning-rate .00001 \
  --reset-std .03 \
  --num-envs 32 \
  --iterations 2 \
  --output outputs/reproduction/sideflip_smoke01
```

## 5. 输出与验收

检查`completion.json`、`env.yaml`、`agent.yaml`、`fixstand.json`、`contract.json`和模型。烟测的`physical_statistics.json`必须确认每个50Hz控制周期有10个物理样本；传感器周期与物理步长均为0.002秒。

完成训练后按仿真手册验收固定模型。至少独立四种子，记录失败；新训练不承诺与历史权重逐位相同。

## 6. 常见问题与下一步

找不到模块：确认当前目录为仓库根目录，并source环境文件。找不到解释器：核对`CPU_PY`与`ISAAC_PY`，二者不能混用。输出目录已存在：换一个新目录，不删除旧实验。显存不足：降低环境数，并把改变后的参数保存到新实验记录。

每次保留原始命令、实际配置、模型SHA256和完整日志；退出码0不等于动作通过。继续阅读[训练手册](训练手册.md)、[仿真手册](仿真手册.md)、[部署手册](部署手册.md)。
