# Go2 侧空翻仿真手册

## 1. 目标与当前边界

必须使用与训练对应的参考、默认站姿、69维观测、动作映射和电机模型；参考哈希不匹配时停止，不删除校验。参考转换是运动学预处理，不是动作成功证据。

## 2. 环境与前置条件

本手册使用Linux Bash；先完成[环境准备与路径约定](../../docs/环境准备与路径约定.md)。每个新终端在仓库根目录运行`source scripts/docs_env.sh`。变量只表示你自己的安装位置，不依赖原服务器。

## 3. 选择权重与配置

```bash
export SOURCE="$ROB2NAV_UPSTREAMS/GO2_backflip"
export RUN=outputs/reproduction/sideflip_run01
export MOTION="$ROB2NAV_ROOT/artifacts/fixstand_best_flips_20261022/outputs/fixstand_finetune_20261021/sideflip.npz"
test -f "$RUN/completion.json"
MODEL=$(find "$RUN" -maxdepth 1 -name 'model_*.pt' | sort -V | tail -n 1)
test -n "$MODEL"
"$CPU_PY" -m rob2nav.export_actor --checkpoint "$MODEL" --output "$RUN/exported"
```

示例先导出自己的完整训练；若只想重放旧归档，明确设置RUN为归档目录并确认同名policy.json与参考哈希。不要给旧策略单独加裁剪后冒充原训练合约。

## 4. 执行与观察

```bash
"$CPU_PY" -m rob2nav.mujoco_skill \
  --kind sideflip \
  --policy "$RUN/exported/policy.pt" \
  --motion "$MOTION" \
  --backflip-source "$SOURCE" \
  --seconds 8 \
  --physics-hz 1000 \
  --fixstand-roundtrip \
  --diagnostics \
  --video \
  --seed 15100 \
  --output outputs/reproduction/sideflip_seed15100
```

首次回合完成后，再固定同一权重换四个独立种子和新输出目录；不要把调参种子混入独立验收。

## 5. 输出与验收

查看输出目录的`summary.json`、逐步轨迹和原速录像。同时检查完整动作、首尾FIXSTAND、身体触地、逐物理步URDF速度/限位；未通过任一项不得晋级。侧翻另查安静准备段和方向，直立另查真实承重，不能只看机身角度。

## 6. 常见问题与下一步

找不到模块：确认当前目录为仓库根目录，并source环境文件。找不到解释器：核对`CPU_PY`与`ISAAC_PY`，二者不能混用。输出目录已存在：换一个新目录，不删除旧实验。仿真黑屏：检查EGL/OpenGL及渲染日志；连接设备前，先核对该机架构、SDK和推理依赖。

每次保留原始命令、实际配置、模型SHA256和完整日志；退出码0不等于动作通过。继续阅读[训练手册](训练手册.md)、[仿真手册](仿真手册.md)、[部署手册](部署手册.md)。
