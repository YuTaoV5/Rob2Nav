# Go2 直立技能部署手册

## 1. 目标与当前边界

本手册是实机接入与验收方案，不能把安装SDK或仿真通过当作设备已合格。先完成[仿真手册](仿真手册.md)，再阅读[统一Go2部署框架](../../docs/统一部署框架与状态机.md)和[Go2 Edu按键热切换](../../docs/Go2Edu按键热切换指南.md)。研究候选未验收时保留禁用状态，不通过修改标记绕过。

## 2. 环境与前置条件

本手册使用Linux Bash；先完成[环境准备与路径约定](../../docs/环境准备与路径约定.md)。每个新终端在仓库根目录运行`source scripts/docs_env.sh`。变量只表示你自己的安装位置，不依赖原服务器。

实机控制在Go2 Edu机载电脑的本地Linux进程中运行。记录设备IP、登录账号、SDK提交、固件、机器人侧有线网卡和控制权限；这些值由你的设备决定，不预设原服务器账号或地址。

## 3. 准备模型与控制合约

48维旧观测与52维相位观测不能互换；需要真实机身速度估计。原地静止、踏步动平衡与前移步行必须独立定义目标、训练与验收。原地踏步要求真实足端交替抬起再落地，腿部/膝部撑地不计正常足端支撑；细则见后翻参考连续性与踏步验收记录。

将权重、导出元数据、参考/感知适配、标定与SDK版本一起传到机载电脑，核对SHA256。模型关节名、观测维度、动作历史、单位、频率和PD必须一致。未实现的传感器/低层适配不是一条运行命令能够补齐的。

## 4. 先离线检查，再连接设备

在机载电脑克隆本仓库、准备依赖后，仅检查已登记合约：

```bash
source scripts/docs_env.sh
"$CPU_PY" -m rob2nav.deployment --root "$ROB2NAV_ROOT" profiles
"$CPU_PY" -m rob2nav.deployment --root "$ROB2NAV_ROOT" plan --from stand --to walk_moe
```

这两个命令不初始化DDS、不发送电机指令。具体技能尚无完整合约时会列出阻止原因；不要把计划打印出来误认为部署成功。感知MoE、托爪及尚未验收的特技，不因存在通用SDK发送器就自动获得适配。

连接机载电脑的通用形式是在操作者电脑执行`ssh -p "$SSH_PORT" "$SSH_USER@$SSH_HOST"`；三个变量分别填设备SSH端口、账号和IP。机器人侧网卡用`ip -br addr`确认。完整服务参数、键盘按键和状态机见上面的统一指南，不复制旧机器绝对路径。

## 5. 输出与验收

依次完成只读状态采集、录制输入的离线推理对齐、关节映射/符号验证、站姿接管、独立动态回合及异常接管验证。保留实测q/dq/tau、IMU、接触、目标、时戳、推理年龄和发送周期，以及模型/SDK/标定哈希。

不允许多个单技能程序同时写电机。低层控制与浏览器/远程SSH会话分开，模型卡顿时由本地经过验证的控制状态接管。实机结论必须来自这台设备的实际记录，不能由上游演示或MuJoCo成绩推导。

## 6. 常见问题与下一步

找不到模块：确认当前目录为仓库根目录，并source环境文件。找不到解释器：核对`CPU_PY`与`ISAAC_PY`，二者不能混用。输出目录已存在：换一个新目录，不删除旧实验。仿真黑屏：检查EGL/OpenGL及渲染日志；连接设备前，先核对该机架构、SDK和推理依赖。

每次保留原始命令、实际配置、模型SHA256和完整日志；退出码0不等于动作通过。继续阅读[训练手册](训练手册.md)、[仿真手册](仿真手册.md)、[部署手册](部署手册.md)。
