# Go2 直立技能训练手册

## 1. 目标与当前边界

当前可执行入口包括历史直立行走训练与原地静止平衡训练。新的“原地踏步动平衡”不能由零速度行走或静止保持自动代替：服务器已实现独立upright_step评估，但尚无验收通过的新踏步权重。下面复现已实现的静止训练，不能将它称作踏步完成。

## 2. 环境与前置条件

本手册使用Linux Bash；先完成[环境准备与路径约定](../../docs/环境准备与路径约定.md)。每个新终端在仓库根目录运行`source scripts/docs_env.sh`。变量只表示你自己的安装位置，不依赖原服务器。

训练必须使用Isaac解释器。运行前查看GPU占用，确认没有同名任务；本手册命令不会自动接管现有训练。

## 3. 准备输入文件

```bash
export SOURCE="$ROB2NAV_UPSTREAMS/GO2_backflip"
export UNITREE_SOURCE="$ROB2NAV_UPSTREAMS/unitree_rl_lab"
export PARENT="$ROB2NAV_ROOT/artifacts/fixstand_upright_v3_20261022/outputs/fixstand_upright_tight_endpoint_v3_20261022/model_2998.pt"
test -f "$PARENT"
sha256sum "$PARENT"
```

每个`test -f`都应成功，缺文件时按总览获取，不能复制原服务器的绝对路径。

## 4. 先烟测，再正式训练

烟测用于确认模型、数据和保存流程接通，不用于证明收敛：

```bash
"$ISAAC_PY" -m skills.upright_walk.train \
  --backflip-source "$SOURCE" \
  --unitree-source "$UNITREE_SOURCE" \
  --resume "$PARENT" \
  --headless \
  --device cuda:0 \
  --transfer-motors \
  --stationary-upright \
  --fixstand-roundtrip \
  --endpoint-residual \
  --endpoint-residual-limit .05 \
  --upright-reset-fraction .5 \
  --reset-std .08 \
  --finetune-learning-rate .00003 \
  --num-envs 32 \
  --iterations 2 \
  --output outputs/reproduction/upright_smoke01
```

核对下节的实际输出，再启动正式预算；输出目录已存在时换新名字：

```bash
"$ISAAC_PY" -m skills.upright_walk.train \
  --backflip-source "$SOURCE" \
  --unitree-source "$UNITREE_SOURCE" \
  --resume "$PARENT" \
  --headless \
  --device cuda:0 \
  --transfer-motors \
  --stationary-upright \
  --fixstand-roundtrip \
  --endpoint-residual \
  --endpoint-residual-limit .05 \
  --upright-reset-fraction .5 \
  --reset-std .08 \
  --finetune-learning-rate .00003 \
  --num-envs 4096 \
  --iterations 1800 \
  --output outputs/reproduction/upright_run01
```

## 5. 输出与验收

检查模型、`completion.json`及实际YAML，三个速度指令都应为0，并存在stationary_balance奖励。训练含动作段初始化，但独立验收必须从四足站姿起始，不能用空中初始化冒充起立。

完成训练后按仿真手册验收固定模型。至少独立四种子，记录失败；新训练不承诺与历史权重逐位相同。

## 6. 常见问题与下一步

找不到模块：确认当前目录为仓库根目录，并source环境文件。找不到解释器：核对`CPU_PY`与`ISAAC_PY`，二者不能混用。输出目录已存在：换一个新目录，不删除旧实验。显存不足：降低环境数，并把改变后的参数保存到新实验记录。

每次保留原始命令、实际配置、模型SHA256和完整日志；退出码0不等于动作通过。继续阅读[训练手册](训练手册.md)、[仿真手册](仿真手册.md)、[部署手册](部署手册.md)。
