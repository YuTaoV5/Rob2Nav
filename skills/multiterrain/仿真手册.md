# Go2 混合地形仿真手册

## 1. 目标与当前边界

这里使用原生PhysX评估感知策略；网页MuJoCo中原始MoE楼梯/高台演示是另一个模型与协议，不能相互借用成绩。混合地形逐个评估flat、stairs、platform，评估器不存在`--kind mixed`。

## 2. 环境与前置条件

本手册使用Linux Bash；先完成[环境准备与路径约定](../../docs/环境准备与路径约定.md)。每个新终端在仓库根目录运行`source scripts/docs_env.sh`。变量只表示你自己的安装位置，不依赖原服务器。

## 3. 选择权重与配置

```bash
export MOE="$ROB2NAV_ROOT/vendor/RoboGauge/resources/models/go2/go2_moe_cts_137k_0.6739.pt"
export CKPT="$ROB2NAV_ROOT/outputs/reproduction/multiterrain_run01/model_199.pt"
test -f "$MOE" && test -f "$CKPT"
sha256sum "$CKPT"
```

训练模型直接交给原生评估器，不将完整感知策略误当45维MoE或只导出最后一层。首回合录屏可在新的输出目录增加`--video --enable_cameras`。再使用种子802、803及新目录复测。

## 4. 执行与观察

```bash
"$ISAAC_PY" -m moe_perceptive.evaluate --headless --device cuda:0 \
 --moe "$MOE" --checkpoint "$CKPT" --kind flat --difficulty 0 \
 --num-envs 32 --seed 801 --memory-lifetime 4 --sensor-rig original --course original \
 --output outputs/reproduction/multiterrain_evaluation/flat_seed801
"$ISAAC_PY" -m moe_perceptive.evaluate --headless --device cuda:0 \
 --moe "$MOE" --checkpoint "$CKPT" --kind stairs --difficulty .5 \
 --num-envs 32 --seed 801 --memory-lifetime 4 --sensor-rig original --course original \
 --output outputs/reproduction/multiterrain_evaluation/stairs_seed801
"$ISAAC_PY" -m moe_perceptive.evaluate --headless --device cuda:0 \
 --moe "$MOE" --checkpoint "$CKPT" --kind platform --difficulty .5 \
 --num-envs 32 --seed 801 --memory-lifetime 4 --sensor-rig original --course original \
 --output outputs/reproduction/multiterrain_evaluation/platform_seed801
```

首次回合完成后，再固定同一权重换四个独立种子和新输出目录；不要把调参种子混入独立验收。

## 5. 输出与验收

查看输出目录的`summary.json`、逐步轨迹和原速录像。检查完整路线、碰撞/跌倒、终点停稳以及传感器策略来源；不能用teacher-map或shallow-probe诊断代替。

## 6. 常见问题与下一步

找不到模块：确认当前目录为仓库根目录，并source环境文件。找不到解释器：核对`CPU_PY`与`ISAAC_PY`，二者不能混用。输出目录已存在：换一个新目录，不删除旧实验。仿真黑屏：检查EGL/OpenGL及渲染日志；连接设备前，先核对该机架构、SDK和推理依赖。

每次保留原始命令、实际配置、模型SHA256和完整日志；退出码0不等于动作通过。继续阅读[训练手册](训练手册.md)、[仿真手册](仿真手册.md)、[部署手册](部署手册.md)。
