# Go2 后空翻仿真手册

## 1. 目标与当前边界

MuJoCo使用自由机身、真实关节与接触。默认示例重放仓库归档v7，不会把你刚训练的权重自动替换进去。它只证明这个权重在本次场景的结果。

## 2. 环境与前置条件

本手册使用Linux Bash；先完成[环境准备与路径约定](../../docs/环境准备与路径约定.md)。每个新终端在仓库根目录运行`source scripts/docs_env.sh`。变量只表示你自己的安装位置，不依赖原服务器。

## 3. 选择权重与配置

```bash
export SOURCE="$ROB2NAV_UPSTREAMS/GO2_backflip"
export RUN="$ROB2NAV_ROOT/artifacts/backflip_v7_verified_20261022/outputs/fixstand_backflip_upstream_actor_v7_20261022"
test -f "$RUN/exported/policy.onnx"
sha256sum "$RUN/exported/policy.onnx"
```

若评估自己的训练，先将RUN设为`outputs/reproduction/backflip_run01`，选择实际最终检查点并导出：
```bash
RUN=outputs/reproduction/backflip_run01
test -f "$RUN/completion.json"
MODEL=$(find "$RUN" -maxdepth 1 -name 'model_*.pt' | sort -V | tail -n 1)
test -n "$MODEL"
"$CPU_PY" -m skills.backflip.export_cpu --checkpoint "$MODEL" --output "$RUN/exported"
```
导出后运行上面的仿真命令；不要同时套用上游默认action_clip、kp/kd或另一套电机曲线。

## 4. 执行与观察

```bash
"$CPU_PY" -m skills.backflip.simulate \
  --source "$SOURCE" \
  --onnx "$RUN/exported/policy.onnx" \
  --seconds 5 \
  --physics-hz 1000 \
  --direction back \
  --fixstand-roundtrip \
  --diagnostics \
  --video \
  --seed 15000 \
  --output outputs/reproduction/backflip_seed15000
```

首次回合完成后，再固定同一权重换四个独立种子和新输出目录；不要把调参种子混入独立验收。

## 5. 输出与验收

查看输出目录的`summary.json`、逐步轨迹和原速录像。同时检查完整动作、首尾FIXSTAND、身体触地、逐物理步URDF速度/限位；未通过任一项不得晋级。侧翻另查安静准备段和方向，直立另查真实承重，不能只看机身角度。

## 6. 常见问题与下一步

找不到模块：确认当前目录为仓库根目录，并source环境文件。找不到解释器：核对`CPU_PY`与`ISAAC_PY`，二者不能混用。输出目录已存在：换一个新目录，不删除旧实验。仿真黑屏：检查EGL/OpenGL及渲染日志；连接设备前，先核对该机架构、SDK和推理依赖。

每次保留原始命令、实际配置、模型SHA256和完整日志；退出码0不等于动作通过。继续阅读[训练手册](训练手册.md)、[仿真手册](仿真手册.md)、[部署手册](部署手册.md)。
