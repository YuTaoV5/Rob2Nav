# Go2 后空翻训练手册

## 1. 目标与当前边界

本流程复现有入口/回收阶段的后翻续训。下文固定v7父权重复现一条续训配方；网站已有更新的v8仿真记录，见[后翻参考连续性与踏步验收记录](../../docs/后翻参考连续性与踏步验收记录.md)。实机落地不稳定的反馈尚未完成验证，不能称为可直接实机部署。0.15入口残差来自受控探索，重新训练后仍须独立验收。

## 2. 环境与前置条件

本手册使用Linux Bash；先完成[环境准备与路径约定](../../docs/环境准备与路径约定.md)。每个新终端在仓库根目录运行`source scripts/docs_env.sh`。变量只表示你自己的安装位置，不依赖原服务器。

训练必须使用Isaac解释器。运行前查看GPU占用，确认没有同名任务；本手册命令不会自动接管现有训练。

## 3. 准备输入文件

```bash
export SOURCE="$ROB2NAV_UPSTREAMS/GO2_backflip"
export PARENT="$ROB2NAV_ROOT/artifacts/backflip_v7_verified_20261022/outputs/fixstand_backflip_upstream_actor_v7_20261022/model_1999.pt"
test -f "$PARENT"
git -C "$SOURCE" rev-parse HEAD
sha256sum "$PARENT"
```

每个`test -f`都应成功，缺文件时按总览获取，不能复制原服务器的绝对路径。

## 4. 先烟测，再正式训练

烟测用于确认模型、数据和保存流程接通，不用于证明收敛：

```bash
"$ISAAC_PY" -m skills.backflip.train_isaac51 \
  --source "$SOURCE" \
  --fixstand-roundtrip \
  --delayed-entry \
  --entry-hold-scale .15 \
  --urdf-speed-limits \
  --fast-safety-curriculum \
  --safety-start 1 \
  --finetune-learning-rate .00001 \
  --reset_optimizer \
  --min_action_std .05 \
  --max_action_std .10 \
  --resume \
  --checkpoint "$PARENT" \
  --trainer rsl_rl \
  --headless \
  --device cuda:0 \
  --seed 50 \
  --num_envs 32 \
  --max_iterations 2 \
  --fixstand-output outputs/reproduction/backflip_smoke01
```

核对下节的实际输出，再启动正式预算；输出目录已存在时换新名字：

```bash
"$ISAAC_PY" -m skills.backflip.train_isaac51 \

```

## 5. 输出与验收

必须存在`completion.json`、`params/env.yaml`、`params/agent.yaml`、`fixstand.json`与模型；实际YAML应为5秒回合、1秒入口、entry_hold_scale=0.15。恢复权重后编号继续累计，不能把800次继续更新误认为`model_799.pt`。

完成训练后按仿真手册验收固定模型。至少独立四种子，记录失败；新训练不承诺与历史权重逐位相同。

## 6. 常见问题与下一步

找不到模块：确认当前目录为仓库根目录，并source环境文件。找不到解释器：核对`CPU_PY`与`ISAAC_PY`，二者不能混用。输出目录已存在：换一个新目录，不删除旧实验。显存不足：降低环境数，并把改变后的参数保存到新实验记录。

每次保留原始命令、实际配置、模型SHA256和完整日志；退出码0不等于动作通过。继续阅读[训练手册](训练手册.md)、[仿真手册](仿真手册.md)、[部署手册](部署手册.md)。
